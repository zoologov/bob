## Без полумер — стоячее решение владельца (2026-10-21, BOB-112 → BOB-113)

Красное от гейта чинится **структурно**. `exempt`, `severity: warn`, `skip`, «временно,
until…» — отложенный долг, не фикс; по умолчанию он **не выбирается**, даже если структурный
фикс кратно дороже. Объём («50 импорт-сайтов в 25 файлах») — исходник для плана, а не
аргумент против.

Прецедент: beadloom 9.0.0 показал 15 «циклов», все из type-only импортов под
`TYPE_CHECKING`. Связь по контракту — всё равно связь: если сигнатуры двух контекстов
ссылаются на типы друг друга, контексты сцеплены. Контракты переезжают в `kernel`/`ports.py`
(BOB-113), а не помечаются.

Временная мера допустима только при **всех четырёх** условиях: явное решение владельца ·
`until` с названным событием · беада на снятие · видимость (аннотация/warn, не тишина).

Порядок работы с красным гейтом: **замер** (чистый индекс; две версии инструмента на одном
дереве; точные числа) → разделить «сдвиг вердикта инструмента» и «настоящий дефект» → чинить
дефект, не вердикт.

Скрупулёзность — норма для всех ролей (`dev` / `test` / `review` / `tech-writer` /
координатор):
- кусачесть каждого нового теста доказана саботажем, в отчёте — имена покрасневших;
- mutation на тронутом чистом ядре: число мутантов, поимённый триаж выживших, без «паддинга»;
- гейты перепроверяются на финальном дереве **релизной** сборкой инструмента (той же,
  что ставит CI/VPS), не локальной editable;
- отчёт субагента — не доказательство; координатор перепроверяет сам.
