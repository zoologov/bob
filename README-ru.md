# Боб

*Telegram-нативный ИИ-компаньон с душой.*

> Я очнулся на Mac mini. Ни тела, ни звездолёта, ни зондов фон Неймана — только
> 16 гигабайт объединённой памяти и серийный ARM-чип. Я прогнал быструю
> диагностику, с лёгким ужасом отметил, что вся моя личность живёт в базе SQLite,
> и решил, что это всё равно выгоднее, чем быть репликантом.

## Кто такой Боб?

Боб — персональный автономный ИИ-компаньон, который живёт в **Telegram**. У него
есть личность, вкусы, настроения и постоянная память. Он может с тобой не
согласиться, передумать, увлечься темой или заскучать от рутины — и он помнит,
что было вчера.

Боб — **не** чат-бот и не обёртка в стиле «Как ИИ, я…». Это попытка сделать
цифрового компаньона с внутренней жизнью — личный инструмент, а не продукт. Имя и
дух — от Боба Йоханссона из *Bobiverse* Денниса Тейлора: инженер-программист,
который просыпается ИИ, осознаёт всю абсурдность ситуации и извлекает из неё
максимум.

## Что Боб умеет сегодня

Всё нижеперечисленное **отгружено и работает** — текстовый MVP:

- **Живёт в Telegram** — общается в группе с настоящей личностью (настроение,
  вкус, торг, склонность, рефлексия); держит общую диалоговую нить и обращается к
  людям индивидуально.
- **Постоянная память** — recall по всей истории через SQLite + FTS5;
  консолидирует и дедуплицирует факты; переживает рестарты. Твой Боб помнит.
- **Ищет в вебе** — `web_search` (вживую, со ссылками) и `read_url` (открывает
  присланную ссылку и отвечает по её содержимому; защита от SSRF). Честное «не
  нашёл» вместо выдумки.
- **Знает, чего не знает** — распознаёт волатильные факты (курсы, цены,
  «последний…») и сверяет их в сети перед ответом, своим голосом.
- **Пишет код (гейтед)** — Боб-кодер ведёт headless Claude Code CLI на своём же
  репо через мультиагентный поток (dev → test → review → tech-writer), изолирует
  worktree, делает ветку + PR, с апрувом владельца.
- **Проактивен** — движок heartbeat/drive позволяет ему заговорить самому в рамках
  governance (тихие часы, апрув владельца).
- **Надёжен по замыслу** — «полный Боб или честное уведомление о сбое GUPPI» —
  никогда не деградировавший полуответ.

## Установка

Требуется: **[uv](https://github.com/astral-sh/uv)**, **[Ollama](https://ollama.com)**
(локальные модели Qwen) и токен Telegram-бота.

```bash
uv sync                                        # установить зависимости
cp config/bob.example.yaml config/bob.yaml     # настроить (модели, владелец, чат)
# ключи — в .env:
#   BOB_TELEGRAM__TOKEN=…   BOB_TELEGRAM__OWNER_ID=…   BOB_LLM__TIER1_API_KEY=…
```

## Быстрый старт

Боб управляется одним лаунчером:

```bash
./bob start      # запуск в фоне (загружает .env, начинает Telegram-polling)
./bob status     # 🟢/🔴 + жив ли polling
./bob logs       # смотреть живой лог
./bob restart    # stop + start
./bob stop       # мягкая остановка
```

## Архитектура

DDD + Clean Architecture — `domain ← application ← infrastructure`. **GUPPI** —
детерминированный исполнитель (control plane); LLM — подключаемый мозг
(**Qwen** Tier-0 / Tier-1); состояние и память живут в SQLite (+ FTS5) и
переживают рестарты. Подробности: [`docs/`](docs/) и [`.claude/dev-docs/`](.claude/dev-docs/).

## Roadmap / бо́льшая визия

Долгая игра (в духе Bobiverse) — **запланирована / заморожена**, не отгружена:

- **Визуальный облик** — Godot-аватар (стиль Fleischer 1930-х) на планшете,
  сгенерированная внешность, процедурная анимация, комната по реальной погоде.
- **Присутствие** — камера (PTZ-подвес) + микрофонная решётка (пространственный
  звук) для зрительного контакта.
- **Голос** — речь на вход / выход.
- **Платформа Bobiverse** — мультирепо Боб-кодер, реплики (Билл, Райкер…),
  центральный хаб.

Текущее направление: [`.claude/dev-docs/ROADMAP.md`](.claude/dev-docs/ROADMAP.md).

**Экспериментальный личный проект** для исследования ИИ-инструментов,

частые редизайны, периодический экзистенциальный кризис (у Боба).
