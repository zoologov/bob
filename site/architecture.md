# Architecture

Generated by `beadloom docs site` from the indexed graph — never hand-drawn. Domains and services are boxes around their features and components. Each edge kind — `depends_on`, `uses`, `consumes` and `produces` — has its own line, with its arrow at the edge's target, and the legend lists the kinds drawn. The lanes are the declared layers, top to bottom: runtime → infrastructure → application → domain. Select a node to open its card and mark its neighbourhood; the toolbar sets how deep and in which direction it reaches, and **Impact** shows everything that depends on the node, ring by ring, with the risky nodes marked. Filter by kind, domain, layer or name, or show only the flagged nodes. The view's state is in the URL, so a view can be linked.
