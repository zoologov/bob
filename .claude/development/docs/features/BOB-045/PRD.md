# PRD: BOB-045 — «Память диалога по персоне + длинные паузы»

> **Status:** Approved
> **Created:** 2026-06-26
> **Feature:** BOB-045 (Тир-1 «Личность» / человечность, мульти-парти) · эпик `bob-045`

---

## Контекст

BOB-044 расширил окно недавней истории до ~14 ходов, но реплей **глобален** (последние ходы независимо
от того, кто писал) и **только для owner** (`[] if is_guest` — гость не получает истории вовсе). Боб уже
**различает собеседников** (BOB-019 `Interlocutor`: owner/known/guest/bot + sender_id), помнит **отношения**
(BOB-014) и **первое впечатление** (BOB-019), и имеет **семантический recall** (FTS5+vec). Не хватает
самого человеческого — **памяти разговора С КОНКРЕТНЫМ человеком**, переживающей паузы.

## Проблема

Человечность — наш главный приоритет, но Боб «помнит» не по-человечески:
- **Гость без памяти.** Норман (друг owner'а, часто тестирует) для Боба каждый раз как впервые —
  компоновка реплики не видит его прошлых ходов (`[] if is_guest`). Нить с гостем не держится вообще.
- **Глобальное окно теряет нить через паузу.** Поговорили с Норманом вечером → ночь/день пауза → за это
  время были другие ходы → диалог с Норманом «уехал» из последних ~14 глобальных ходов. Продолжить «как
  ни в чём не бывало» (как люди с друзьями) — нельзя.
- **Нет per-person нити.** Боб не реплеит «где мы остановились С ЭТИМ человеком»; в многолюдном чате его
  ходы с owner и с Норманом смешаны в одном глобальном окне.

## Цель

Боб **помнит каждого собеседника как человек**: продолжает диалог с owner и с гостем (Норманом и др.)
по их **личной нити** — недавние ходы именно с этим человеком — и **переживает длинные паузы** (ночь/
день): возвращается к беседе естественно, как со старым другом. В многолюдном чате держит **отдельные
нити** с каждым, ссылается на «что говорил Норман» vs «что говорил ты».

## 🔴 Безопасность (BOB-019: социальная память ≠ authz)

Социальная память (помнить разговор с человеком) — **НЕ** доступ к данным:
- Гость видит в контексте **только свою нить** — свои ходы + ответы Боба ему. **Никогда** не приватную
  переписку owner'а / чужие нити. Нельзя просто снять `[] if is_guest` (глобальное окно утечёт owner-
  приватное гостю).
- Authz-инвариант BOB-019 цел: гость по-прежнему **без доступа** к возможностям/приватной памяти owner'а.
  Меняется только что Боб **помнит свой разговор** с гостем.

## Пользовательские истории

- **US-1 (нить гостя).** Норман поговорил с Бобом, вернулся через час → Боб помнит их разговор и
  продолжает, а не «знакомится заново».
- **US-2 (длинная пауза).** owner общался вечером, продолжил на следующий день «а помнишь, мы говорили…»
  → Боб помнит, подхватывает нить (per-person свежесть + recall старых колбэков), не теряет тему за паузу.
- **US-3 (мульти-парти).** В чате owner и Норман пишут вперемешку → Боб держит ДВЕ отдельные нити,
  отвечает каждому в контексте именно их разговора, не путает.
- **US-4 (🔴 приватность).** Гость Норман НЕ видит в ответах Боба приватную переписку owner'а; Боб не
  утекает чужую нить. Authz BOB-019 не ослаблен.
- **US-5 (текстура «давно не виделись», опц.).** После долгой паузы Боб по-человечески отмечает разрыв
  («давно тебя не было») — естественно, не механически.

## Критерии успеха

- Боб продолжает диалог по **личной нити** с owner и с гостем; длинная пауза (ночь/день) не теряет тему
  (US-1/2/3) — проверяемо: после паузы релевантные прошлые ходы С ЭТИМ человеком в контексте.
- **🔴 Приват-инвариант:** гость видит только свою нить, не owner-приватное / не чужую нить; authz BOB-019
  не ослаблен (US-4).
- Без регрессий (BOB-044 окно, anti-repeat, recall-grounding, owner-диалог, BOB-019/014).

## Объём

**В объёме:** (1) **структурная атрибуция** — `sender_id` в `episodic_log` (+ запись на сохранении +
бэкафилл существующих по имени-префиксу best-effort); (2) **per-person replay** — компоновка реплеит
недавние ходы **с текущим собеседником** (по `Interlocutor.sender_id`), не глобально; (3) **гость
authz-safe** — у гостя своя нить (его ходы + ответы Боба ему), вместо `[] if is_guest`; (4) длинные паузы
— per-person свежесть + существующий recall для старых колбэков; (5) опц. текстура «давно не виделись»
(маркер времени с последнего хода персоны). Реюз BOB-019 (`Interlocutor`), BOB-014 (отношения), recall.

**Вне объёма:** полный граф «кто-кому-что» / cross-person reasoning сверх ссылок; смена authz-инварианта;
RAG-суммаризация долгих историй (есть консолидация BOB-021 — отдельно); bot-to-bot нити (BobNet — Тир-3).

## Связи и принципы

- Поверх **BOB-044** (конфиг-окно + полный реплей), **BOB-019** (`Interlocutor`/identity/authz два слоя),
  **BOB-014** (отношения per-person), recall (BOB-011/021). Маркер **автобиографической памяти**
  (функц. коррелят сознания, VISION §4.2). Память: `bob-social-identity-strangers`,
  `bob-personality-simulation-philosophy`.
