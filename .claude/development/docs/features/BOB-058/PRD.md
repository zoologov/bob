# PRD: BOB-058 — «Нить связанности в группе» (общий диалоговый тред)

> **Status:** Approved
> **Created:** 2026-07-01
> **Feature:** BOB-058 · Тир-1 (личность/диалог) · фикс пер-персона-нити в группе (BOB-045/025/051)

---

## Контекст

В закрытой группе Bobiverse теперь несколько живых участников (Владимир, Алексей, Норман). Диагностика
(2026-07-01, реальная переписка) вскрыла дыру: **свежий диалоговый тред у Боба проигрывается пер-персона**
(`_replay_person_history` → `recent_episodes_for(sender_id, k)`, BOB-045). Для распознанного собеседника
Боб видит **только свои последние ходы с ним** — не общий разговор группы.

Живой сбой: Алексей писал про фильм в 15:34–15:44 (тред Алексея). Владимир в 16:41 просит «ответь на
сообщение Лёши про фильм» → Боб проигрывает **тред с Владимиром**, где сообщений Лёши нет → честно
отвечает «в нашей переписке нет никакого сообщения Лёши про фильм». Нить порвалась. Заработало только
когда Владимир **вручную вставил** текст Лёши.

Память фактов у Боба уже общая (BOB-051 объединил recall), а вот **свежий разговорный тред остался
пер-персона** — и в настоящей многосторонней группе, где участники ссылаются друг на друга, это ломает
связность.

## Проблема

В групповом чате Боб не «слышит» общий недавний разговор: он держит нить только с текущим собеседником.
Ссылки между участниками («ответь на то, что сказал X», «как вы обсуждали») рвутся — Боб не видит
сообщений других людей, даже совсем свежих в том же топике.

## Цель

Чтобы в **публичной группе** Боб проигрывал **общий недавний тред** — последние сообщения **всех**
участников топика (с именами), как человек в комнате слышит всех, — и держал связную нить многостороннего
разговора. Пер-персона-сигналы (отношения, тон, «давно не виделись») остаются, но **связность диалога** —
по общему треду.

## Пользовательские истории

- **US-1 (кросс-персона ссылка — главный).** Алексей обсудил фильм; Владимир просит «ответь Лёше про
  фильм» → Боб **видит** сообщения Лёши в общем треде и отвечает по существу (не «нет такого сообщения»).
- **US-2 (следит за разговором троих).** В группе идёт общий разговор (Владимир + Алексей + Норман) → Боб
  держит нить: понимает, кто что сказал и кому, реагирует уместно (как участник беседы, а не как N
  изолированных 1:1).
- **US-3 (имена в треде).** Общий тред помечает автора каждой реплики (кто сказал) → Боб не путает, кто
  что произнёс, и адресуется правильно.
- **US-4 (отношения/тон целы).** Пер-персона отношения (BOB-014), первое впечатление (BOB-019),
  «давно не виделись» (BOB-045) — по-прежнему по конкретному человеку; ломается только изоляция
  **разговорной нити**, не эти сигналы.
- **US-5 (приват — на будущее).** Если появится личка/DM (приват-скоуп), там тред снова пер-персона
  (приватность). Сейчас существует только публичная группа → общий тред корректен и безопасен (BOB-051).

## Критерии успеха

- Кросс-персона ссылка работает: Боб видит свежие сообщения других участников и отвечает по существу
  (кейс «ответь Лёше про фильм»).
- Боб держит связную нить многостороннего разговора (кто/что/кому).
- Пер-персона отношения/впечатление/absence-hint не сломаны.
- Приватность не нарушена: в публичной группе общий тред — это ОК (память публична, BOB-051); приват
  (будущее) — пер-персона.

## Объём

**В объёме:**
- **Общий недавний тред** для связности в публичной группе: reply-контекст проигрывает
  `recent_episodes(k)` (все участники топика, с именами-метками) вместо/поверх пер-персона слайса
  (`recent_episodes_for`). Порт уже есть (им пользуется BOB-023).
- **Разметка авторства** в треде (кто сказал реплику) — чтобы Боб не путал участников и адресовался верно.
- **Сохранить пер-персона сигналы:** отношения (BOB-014), первое впечатление (BOB-019), absence-hint
  (BOB-045) остаются по конкретному собеседнику.
- **Скоуп-развилка:** публичная группа → общий тред; (будущий) приват/DM → пер-персона (задел, без
  реализации лички сейчас).

**Вне объёма:**
- Личка/DM Боба (приват-скоуп) — только задел развилки, без реализации.
- Изменение семантического recall/памяти (BOB-051 уже объединил — не трогаем).
- Изменение адресности/floor-логики (BOB-023/025) сверх подачи общего треда — переиспользуем.
- Тюнинг размера окна `recent_turns` сверх разумного (можно чуть увеличить для группы — деталь RFC).

## Связи и принципы

- Фикс дыры **BOB-045** (пер-персона тред) в свете **BOB-051** (память публична). Связность/floor —
  **BOB-023/025**; отношения — **BOB-014**; идентичность — **BOB-019**. Порт `recent_episodes` уже есть
  (BOB-023). Принцип: Боб — участник общей беседы, а не N изолированных диалогов. Север:
  `bob-social-identity-strangers`, `bob-telegram-pivot`.
