# BRIEF: BOB-012 — Проактив по-русски + сохраняется в память + grounded в реальной памяти

> **Status:** Approved
> **Created:** 2026-06-21
> **Type:** bug

---

## Проблема

Live: Боб написал проактивно **по-английски**, выдумал «общий момент» (плащ/сушился/«fur safe» — такого
в `episodic_log` нет), и потом **не смог объяснить** своё же сообщение (сконфабулировал рядом по теме).

Три корня (проверены по коду/БД):
1. **Язык:** само-генерируемый текст (проактив-компоновка + Tier-0 гейт + inner monologue + reflection)
   не привязан к языку → модель уходит в дефолтный английский. (Реактив случайно «спасал» русский ввод —
   зеркалил.) Reflect-тики в БД все английские.
2. **Не сохраняется:** `ProactivityEngine` шаг «Persist» пишет в стор только энергию + `last_spoke_at`,
   **реплику в `episodic_log` НЕ пишет** → Боб не помнит, что сказал, не может объяснить/развить.
3. **Не grounded:** компоновка проактива идёт от mood+reflection, но **не тянет реальную память** → Боб
   выдумывает фейковые «общие моменты» вместо ссылки на настоящие.

## Решение

1. **Язык персоны** — конфиг `runtime.language` (дефолт `ru`); инжектить директиву «отвечай/думай на
   <язык>» во ВСЕ само-генерации, где нечего зеркалить: проактив-компоновка + Tier-0 гейт, inner
   monologue тик, reflection тик. (Реактив оставляем — он зеркалит ввод; опц. тоже честит язык.)
2. **Сохранять проактив в эпизодическую память** — после постинга движок пишет реплику в `episodic_log`
   (как реактивный путь сохраняет turn) через инъекцию репо/save-порта → попадает в recall + recent-history.
3. **Grounding в реальную память** — перед компоновкой проактив тянет релевантное через гибрид
   `MemoryRecall` (по mood/reflection-seed/контексту) и кладёт в промпт → Боб ссылается на **реальные**
   моменты/свои рефлексии, не выдумывает.

## Критерии приёмки

- [ ] Проактив, inner monologue и reflection генерятся **по-русски** (config `runtime.language=ru`).
- [ ] Проактив-сообщение **сохраняется в `episodic_log`** → попадает в recall/recent-history; Боб может
      сослаться/объяснить позже.
- [ ] Компоновка проактива **grounded** в реальной памяти (гибрид-recall в промпте) — ссылается на
      настоящие моменты, не выдумывает фейковые.
- [ ] Реактивный чат / тиринг / приватность / governance не сломаны.
- [ ] Тесты ≥80% (на фейках — без сети), `ruff`/`mypy --strict` чисто, `beadloom ci` зелёный.
