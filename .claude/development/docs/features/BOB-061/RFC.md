# RFC: BOB-061 — «Анти-тик / разнообразие реплик»

> **Status:** Approved
> **Created:** 2026-07-01
> **PRD:** `.claude/development/docs/features/BOB-061/PRD.md`
> **Решения (под утв.):** строим на BOB-036/043 (не с нуля) · закрыть 3 пробела — (1) кросс-сессионная
> разреженность → персист «недавних closer-ов» Боба; (2) лексическая вариация → near-verbatim кластеризация
> мотива (реюз `similarity_threshold`); (3) диспозиция — приглушить застревание · всё мягко (нудж, не бан),
> живость/связность целы.

---

## Что УЖЕ есть (не дублировать)

Анти-тик частично реализован (**BOB-036/043**, `domain/personality/conversation.py` +
`handle_message.py`):
- `is_phrase_tic`/`recurring_closer`/`strip_recurring_closer` — детект повторяющейся closer-фразы;
  `RepeatThresholds` (`tic_min_words≈3`, `tic_min_occurrences=2`, широкий `tic_lookback` BOB-043).
- `recalled_without_copied_exemplars` — гашение recall-мимикрии скопированных примеров.
- `is_bob_repeat` (near-verbatim по `similarity_threshold`) — но на уровне ВСЕЙ реплики.

**Почему тик всё равно живёт** (данные 2026-07-01): closer «пусть остаётся как есть. Мне так спокойнее»
дословно повторился 4× — но **раз в сессию, через дни**. В сессионном lookback он встречается 0–1 раз →
ниже `tic_min_occurrences=2` → пропуск. Плюс мотив в вариантах («так спокойнее» / «останется» / «оставить»)
— точный матч недосчитывает. Плюс диспозиция регенерирует мотив после strip.

## Идея решения — закрыть 3 пробела поверх BOB-036/043

### Пробел 1 — кросс-сессионная разреженность (главный): персист closer-ов
Сессионное окно принципиально не видит «раз-в-сессию» тик. Ввести **лёгкий персист последних closer-ов
Боба** (небольшой стор: N последних нормализованных closer-фраз + счётчики), переживающий рестарты. Детектор
тика читает closer-ы **из персиста** (а не только из свежего окна) → «раз-в-сессию, но 4× за неделю» ловится.
Пишется после каждой реплики Боба (как эпизод). Ограниченный размер (кольцо), приватно/локально.

### Пробел 2 — лексическая вафиация: near-verbatim кластеризация мотива
Детект closer-тика — не только по нормализованной ТОЧНОЙ фразе, а с **near-verbatim** порогом (реюз
`similarity_threshold` из `is_bob_repeat`): «пусть остаётся/останется как есть», «мне/ему так спокойнее» —
кластеризуются как ОДИН мотив → счётчик набирается, тик ловится.

### Пробел 3 — диспозиция (приглушить застревание)
«Оставить как есть / так спокойнее» — содержательный лён (BOB-033 диспозиция/reappraisal). Проверить, не
залипает ли reappraisal/диспозиция в комфортной колее, и при подтверждении — **мягко приглушить**
застревание (лёгкий тюнинг, не редизайн BOB-033), чтобы strip не боролся с бесконечной регенерацией мотива.
Если драйвер только текстовый — этот шаг минимален.

## Провязка (application) — мягкий нудж, не бан

- **Детект** (расширенный `is_phrase_tic`/`recurring_closer` с персистом + near-verbatim) → когда мотив
  распознан как тик, **при генерации**: (а) `strip_recurring_closer` из few-shot/recall (уже есть,
  усилить персистом), (б) **лёгкий нудж в контекст**: «эту концовку/оборот ты уже часто использовал —
  скажи по-другому, своими словами» (не бан, не список-запрет; подталкивание к разнообразию).
- 🔴 **Мягко:** нудж/деэмфаз, НЕ жёсткий запрет; связность/характер/легитимные повторы-по-смыслу целы
  (US-4). Детерминизм — seeded/инъекции.

## 🔴 Инварианты / guardrails

- **US-4 живость:** только подталкивание к разнообразию; Боб не выхолащивается/не цензурируется/не
  рандомизируется; связность цела. Тест «характер/связность сохранены».
- **US-5 общий:** ловит ЛЮБОЙ повторяющийся мотив (персист+near-verbatim), без хардкода конкретной фразы.
- **Приватность/локальность:** персист closer-ов — локально, приватно (как память Боба), ограниченный размер.
- **Не ломаем:** BOB-036/043 текущий детект (расширяем, не заменяем); recall/память (BOB-011/051) —
  только гашение мимикрии; BOB-033 — мягкий тюнинг, не редизайн.
- **Декоративность:** сбой детекта/персиста → обычная реплика (не блокирует ход).

## Слои (DDD)

- **domain:** расширить `conversation.py` (near-verbatim в phrase-tic; чистые функции детекта над списком
  closer-ов); значение «closer-запись».
- **application:** нудж в reply-контекст при распознанном тике; чтение/запись персиста closer-ов в
  `handle_message`.
- **infrastructure:** лёгкий стор persisted-closers (SQLite, как прочая память Боба) + порт.
- **диспозиция:** точечный тюнинг `disposition.py`/reappraisal-шага, если подтверждён драйвером.

## Риски и митигации

- **🔴 Пере-подавление (выхолащивание)** → мягкий нудж (не бан), консервативные пороги, тест «связность/
  характер целы»; near-verbatim порог не слишком низкий (чтобы не душить любую похожесть).
- **Персист растёт** → кольцо ограниченного размера; только нормализованные closer-ы (не полные реплики).
- **Диспозиция — не драйвер** → тогда шаг 3 минимален (только детект/персист/near-verbatim). Проверить эмпирически.
- **Ложные тики** (легитимный повтор-по-смыслу) → `tic_min_occurrences`/similarity настроены консервативно;
  нудж мягкий (разнообразие, не запрет темы).

## Открытые решения (под утверждение)

1. **Персист closer-ов** (кросс-сессионный, лёгкий SQLite-стор) как основной фикс разреженности —
   **рекомендую** (иначе «раз-в-сессию» тик не поймать в принципе).
2. **Near-verbatim кластеризация мотива** (реюз `similarity_threshold`) — **рекомендую**.
3. **Диспозиция:** мягкий тюнинг ТОЛЬКО при подтверждении драйвером (эмпирически); иначе пропустить —
   **рекомендую** (не редизайнить BOB-033 умозрительно).
4. **Мягкий нудж, не бан** (подталкивание к разнообразию, живость цела) — **рекомендую**.
