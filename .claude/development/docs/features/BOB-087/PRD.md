# PRD — Человечный dev-Боб: GUPPI-исполнитель + Боб-оператор + человечная память

## Видение (owner, детальное обсуждение 2026-08-02)

По канону: **GUPPI — детерминированный исполнитель**, **Боб — разум/личность-оператор**. Боб просит GUPPI
выполнить задачу; GUPPI гонит автоматику (Claude Code CLI); Боб **реагирует и ведёт диалог своим стилем**,
режиссирует как оператор (метафора owner'а: «я Боб, ты мой GUPPI») и **помнит проделанную работу
по-человечески** — детально, но без превращения в робота и без галлюцинаций от смешения работы с общением.

🔴 **Главный страх owner'а:** не сломать/не засорить память Боба. У owner'а мощная человеческая память —
работа И личное И диалоги И настроения — одна, но не путается. Хотим Бобу такую же: **детальную,
человечную, чистую** (без bleed рабочего регистра в личный, без recall-яда).

## Цели эпика (5 срезов A–E)

- **A. GUPPI-канал:** стрим Claude Code уходит **ботом GUPPI** (исполнитель), а не Боба; Боб реагирует
  своим ботом. Отделяет механический firehose от голоса Боба (канон + анти-яд).
- **B. Боб-оператор + богатая дистиллированная память:** Боб режиссирует GUPPI, реагирует своим голосом;
  сессия → **детальные первого-лица эпизоды оператора** (файлы/тесты/что-сломалось/чем-починили —
  дистилляция сути, НЕ сырой firehose). Богаче сегодняшних 5 вех, человечно.
- **C. Целостность памяти:** `work`-домен + провенанс (Боб-решил vs GUPPI-исполнил vs тест-упал) +
  **register-aware recall** (контекстный-но-сквозной: работа громко в dev-разговоре, приглушена в casual,
  но всплывает по релевантности). 🔴 Сердце — ноль засорения личного, ноль путаницы актора.
- **D. Интерактив срез 2 (T3.C⁺):** `--continue`/`--resume` сессии + настраиваемый `permission_mode`
  (вкл. `bypassPermissions` «auto mode») + `--add-dir` — **ослабляют защиту → owner-only, за явным флагом**.
- **E. Устойчивость Tier-0 (#34):** локальный **Ollama-fallback** для Tier-0 при отвале облака (Qwen/
  Aliyun DNS/сеть, 77×/день) — сеть до Aliyun перестаёт быть точкой отказа обычных ответов Боба.

## Инварианты (сквозные)

- **INV-1 (Канон):** firehose исполнения — от GUPPI; голос/реакции/диалог — от Боба (человек, не робот).
- **INV-2 (Человечная детальная память):** работа помнится детально (файлы/тесты/что-сломалось/фикс) как
  первого-лица воспоминание оператора — дистилляция сути, НЕ firehose, НЕ generic-обобщение.
- **INV-3 (Чистота памяти):** рабочая память НЕ засоряет личный/групповой регистр по умолчанию; сквозная
  (всплывает по релевантности); провенанс различает актора → ноль галлюцинаций-от-смешения.
- **INV-4 (Анти-яд):** GUPPI-firehose вне recall/voice-пула Боба; рабочие эпизоды первого-лица (не сырой
  нарратив) → не учат Боба наррировать (урок BOB-074/078).
- **INV-5 (Безопасность):** всё аддитивно + за флагами; личная/социальная память и recall по умолчанию
  байт-в-байт; D-ослабления (bypass/add-dir) owner-only + явный флаг; main неприкосновенен (worktree+PR).
- **INV-6 (Человечность — north star):** на каждом срезе живая проверка «Боб звучит как Боб, не робот».

## Не входит в scope
- Мульти-репо / реплики (Бендер/Билл) / Mini-App хаб (T3.D–H) — отдельный горизонт.
- Полная переработка decide_verbosity/личности — только оператор-грань + память.

## Порядок / риск
A (низкий, канон, сразу видно) → B (средний) → C (🔴 высокий, сердце памяти, осторожно) →
D (🔴 безопасность, за флагом) → E (инфра). Срез за срезом: PR → мерж → рестарт → живая проверка человечности.
