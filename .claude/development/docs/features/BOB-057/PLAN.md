## Критерии приёмки (из PRD)

- Волатильно-зависимый вопрос → Боб сам сверяется, отвечает актуально + живым тоном (кейс Лёши).
- 🔴 Обычная болтовня → НЕ лезет в сеть (0 задержки), не зануда.
- 🔴 Проверяет → один поиск + живая адресная интерим-реплика + честный хедж при затяжке; не «5 минут».
- Работает для любого собеседника (публично, не привилегия BOB-052).
- Не смог свериться → честный хедж, без выдумки.
