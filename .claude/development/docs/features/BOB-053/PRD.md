# PRD: BOB-053 — «Веб-поиск» (`web_search`)

> **Status:** Approved
> **Created:** 2026-07-01
> **Feature:** BOB-053 · Тир-1/2 · навык за capability-швом (BOB-002) · гейт authz (BOB-052)

---

## Контекст

Боб знает свой мир (репо/беады/архитектуру — T3.A) и свою память, но **не видит интернет**. Когда
разговор уходит в актуальное/внешнее («что нового у Qwen», «какие параметры у модели X», «сколько стоит
Y», «что произошло с Z»), Боб отвечает по памяти-обучения — устаревше или «не знаю». По-человечески
компаньон в такой момент **идёт и смотрит** — как мы спрашиваем у Perplexity/поисковика.

Проверено (2026-07-01): провайдер Боба **Qwen MaaS** даёт веб-поиск с источниками штатно — модель
`qwen3.7-plus` с `enable_search` + `enable_source` (нативный DashScope-протокол) возвращает обоснованный
ответ **и список источников** (заголовок + URL). Тот же ключ, без нового провайдера, бесплатно в рамках
текущего MaaS. (OpenAI-совместимый chat/completions источников НЕ отдаёт — поэтому поиск идёт через
нативный вызов.)

## Проблема

На вопрос про актуальное/внешнее Боб не может найти и свериться с реальностью — отвечает по памяти
(устаревше) или отказом. Нет навыка «найти в интернете и ответить со ссылками».

## Цель

Дать Бобу **атомарный навык `web_search`**: на запрос, требующий свежей/внешней информации, Боб делает
**один** поиск (qwen3.7-plus, `enable_search`+`enable_source`), получает ответ + источники и отвечает
**своим голосом с цитатами-ссылками**. Навык — за существующим capability-швом (BOB-002), исполняется
GUPPI через tool-loop, **гейтится authz** (как все привилегированные навыки): owner/allowlist — сразу;
не-авторизованный просящий → флоу разрешения owner (BOB-052).

## Пользовательские истории

- **US-1 (поиск со ссылками).** Owner: «что нового вышло у Qwen на этой неделе?» → Боб ищет → отвечает
  своим голосом с **2–4 источниками** (заголовок + ссылка).
- **US-2 (Боб сам решает искать).** Вопрос явно про актуальное/внешнее, чего нет в памяти → Боб сам
  выбирает навык `web_search` (через tool-loop), не дожидаясь команды «погугли».
- **US-3 (синтез, а не дамп).** Боб не вываливает сырые сниппеты — **синтезирует** ответ своими словами и
  прикладывает источники (как аналитик, а не выдача поисковика).
- **US-4 (authz-гейт).** Не-авторизованный участник просит поиск → срабатывает BOB-052 (спросить owner),
  как для любого привилегированного навыка. Owner/allowlist — без спроса.
- **US-5 (🔴 отказоустойчивость).** Сбой поиска (сеть/MaaS/нет результатов) → Боб не врёт «из головы» под
  видом найденного: честный GUPPI-нотис о недоступности поиска ИЛИ явная оговорка «не нашёл / по памяти»
  (принцип «полный Боб или честный GUPPI-нотис»).

## Критерии успеха

- На вопрос про актуальное/внешнее Боб делает один веб-поиск и отвечает своим голосом **с источниками**
  (заголовок + URL).
- Боб **сам** выбирает навык, когда уместно (tool-loop), не только по явной команде.
- Навык гейтится authz: owner/allowlist — сразу; не-авторизованный → BOB-052.
- 🔴 Сбой/пустой результат → честный нотис/оговорка, без галлюцинации «найденного»; обычный диалог не
  ломается.

## Объём

**В объёме:**
- **Навык `web_search`** за capability-швом (фабрика `make_web_search_capability`, регистрация в
  `CapabilityRegistry`, исполнение через `ToolLoop`/GUPPI).
- **Провайдер поиска** на Qwen MaaS нативно (`qwen3.7-plus`, `enable_search`+`enable_source`) → ответ +
  источники (title/url); порт в domain, реализация в infrastructure.
- **Синтез со ссылками** в голосе Боба; защита от сырого дампа.
- **Гейт authz** (реюз Authorizer/BOB-052) — навык привилегированный.
- Отказоустойчивость: сбой/пусто → честный нотис/оговорка (без выдумки).

**Вне объёма:**
- **`web_research`** (многошаговое агентное расследование: декомпозиция → N поисков → fetch страниц →
  сверка → синтез) — отдельный беад, в ROADMAP T2.3. v1 = атомарный один проход.
- Тонкая настройка ранжирования/числа источников сверх разумного дефолта.
- Поиск картинок/медиа, специализированные источники (только общий веб-поиск).
- Кэш/история поисковых запросов (по необходимости позже).

## Связи и принципы

- За **capability-швом** (BOB-002), исполнение **GUPPI/tool-loop**; гейт **authz** (BOB-019) + флоу
  разрешения **BOB-052**; принцип **«полный Боб или честный GUPPI-нотис»** (BOB-049/ROADMAP #10); синтез
  в голосе Боба (BOB-049). Фундамент под будущий **`web_research`** (T2.3). Север: `bob-post-p0-plan`
  (capability/GUPPI-шов), `bob-telegram-pivot`.
