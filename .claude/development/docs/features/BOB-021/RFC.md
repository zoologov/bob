# RFC: BOB-021 — «Консолидация памяти» (BOB-011 Ф2 · T1.3)

> **Status:** Approved
> **Created:** 2026-06-22

---

## Обзор

3 механизма консолидации поверх памяти Ф1, всё **локально/приватно** (эмбеддер/LLM за портами — в проде
Ollama/MaaS, в тестах фейки), **не деструктивно** (только пометки, оригиналы целы), **идемпотентно**, под
guardrails (консервативные пороги). Дайджесты — обычные строки `episodic_log` (`event_type='digest'`,
эмбеддятся) → ищутся гибрид-recall **наравне**, поэтому `MemoryRecall` остаётся **drop-in**. Фоновые шаги
идут на reflect-тике (как BOB-020), редко, из конфига.

## Технический контекст

### Ограничения
- Python 3.12+, DDD/Clean (домен чист), инъекция `Clock`/портов, TDD на фейках (без сети), `mypy --strict`,
  `ruff`, cov ≥80%.
- **Локальность:** ноль внешних вызовов с контентом памяти. **CI без сети:** эмбеддер/LLM — фейки.
- **Не деструктивно:** оригиналы помечаются, не удаляются. **Drop-in:** потребители `MemoryRecall` не меняются.
- Не ломать: recall Ф1, проактив, выражение (BOB-018), эмоции (BOB-020), тиринг, authz.

### Затрагиваемые области
`infrastructure/persistence/{schema.sql (миграции: `consolidated`, `event_type='digest'`, `superseded_by`),
sqlite_repo.py, hybrid_recall.py (age-aware), vector_store.py}`, `application/usecases/{consolidate_memory.py
(new), dedup_facts.py (new), heartbeat.py (врезка тиков)}`, `domain/{memory, ports.py}`, `app.py`, `config`.

## Предлагаемое решение

### Схема (миграции, идемпотентные `ALTER`/`IF NOT EXISTS`)
- `episodic_log`: **`consolidated INTEGER NOT NULL DEFAULT 0`** — эпизод свёрнут в дайджест.
- **Дайджест** = строка `episodic_log` с `event_type='digest'`, эмбеддится (on-write Ф1) → в recall наравне;
  provenance (диапазон ts / id-источников) в content/служебном поле.
- `semantic_memory`: **`superseded_by INTEGER NULL`** — факт слит в канонический (исключается из recall,
  не удалён).

### (2) Суммаризация / дайджесты — `ConsolidateMemory` (тик)
- Редкий шаг на reflect-тике: выбрать **старые** (старше порога) **не-consolidated** эпизоды пачкой (размер
  из конфига) → суммаризовать **Tier 0** (router, локально) в **дайджест** → записать дайджест-строку
  (эмбеддится) → пометить источники `consolidated=1`. **Идемпотентно:** берём только не-consolidated;
  дайджест (event_type='digest') сам не дайджестится. Guardrails: пороги возраста/размера из конфига,
  не деструктивно. _Q1, Q4._

### (3) Дедуп / слияние фактов — `DedupFacts` (тик)
- Редкий шаг: для фактов `semantic_memory` найти **near-duplicate** по косинусной близости эмбеддингов
  (через vector-store/эмбеддер) **выше консервативного порога** → выбрать канонический (новейший/полнейший),
  остальные пометить `superseded_by=canonical_id` (provenance цел). **Идемпотентно** (superseded
  исключены). **Несхожие не сливаем** (высокий порог). _Q3._

### (1) Всплытие очень старого — age-aware recall + колбэк
- `HybridMemoryRecall`: **аддитивная опция** `surface_old` — в пул кандидатов изредка добавляется
  **старое-но-релевантное** (отдельный KNN/возрастное разнообразие поверх RRF); по умолчанию поведение
  recall **не меняется** (drop-in). Использование — через **колбэк-шов BOB-018** (редко, к месту,
  grounded). _Q2._
- Дайджесты (из мех.2) уже улучшают доступ к старому — старое доступно сжато.

### Каденс / композиция
- `ReflectTick`: после существующих шагов — `ConsolidateMemory` и `DedupFacts` (редко, из конфига
  `memory.consolidation.*` / `memory.dedup.*`, идемпотентно). Эмбеддинг дайджестов — существующий on-write.
- Recall/колбэк: `surface_old` опционально в BOB-018-пути.

## Guardrails (под тестами)
- Не деструктивно: оригиналы (`consolidated=1`) и факты (`superseded_by`) **остаются**; ничего не удаляется.
- Идемпотентность: повтор тика не плодит дайджесты / не пере-сливает (маркеры consolidated/superseded).
- Дедуп консервативен: высокий порог; несхожие факты **не** сливаются (тест на ложные слияния).
- Локальность: эмбеддер/LLM за портами; в тестах фейки; ноль сети.
- Drop-in: дефолтный `recall(query,k)` не меняет контракт/поведение; `surface_old` — опт-ин.

## Рассмотренные альтернативы
- **Деструктивно удалять старое** — отвергнуто: книжный Боб помнит всё; только пометка `consolidated`.
- **Дайджест отдельной таблицей** — отвергнуто: проще строкой `episodic_log` (эмбеддинг/recall наравне, без новых путей).
- **Дедуп по keyword** — отвергнуто: пропустит перефразы; берём эмбеддинги (семантика), консервативно.
- **Surface-old в дефолтном recall** — отвергнуто: риск регрессии релевантности; делаем опт-ин + через колбэк.

## Риски
| Риск | Вер. | Влияние | Митигация |
|---|---|---|---|
| Дайджест теряет важное | Med | Med | Не деструктивно (оригиналы целы); Tier 0 промпт «сохрани факты»; идемпотентно |
| Ложные слияния фактов | Med | High | Консервативный порог + provenance + тест «несхожие не сливаются» |
| Регрессия релевантности recall | Low | Med | `surface_old` опт-ин; дефолт не меняется; контрактные тесты Ф1 |
| Стоимость консолидации | Low | Low | Редко (тик), пачками, из конфига, в фоне |
| Рост БД от дайджестов | Low | Low | Дайджест < суммы источников; источники остаются, но сжаты по доступу |

## Открытые вопросы
| # | Вопрос | Предложение |
|---|--------|-------------|
| Q1 | Tier суммаризации | Tier 0 (дёшево, редко); Tier 1 — опц. при нужде качества |
| Q2 | Механизм всплытия старого | `surface_old` опт-ин в recall + использование через колбэк BOB-018 |
| Q3 | Порог дедупа + кто канонический | Косинус ~0.92+; канонический = новейший/полнейший; остальные superseded |
| Q4 | Пороги возраста/пачки консолидации | В конфиг (напр. старше N дней, пачка M), per-persona; консервативные дефолты |
