# PRD: BOB-021 — «Консолидация памяти» (BOB-011 Ф2 · T1.3)

> **Status:** Approved
> **Created:** 2026-06-22
> **Type:** feature

---

## Контекст (что уже есть)

BOB-011 Ф1 дал Бобу **семантическую/гибридную память**: FTS5 + sqlite-vec + RRF за портом `MemoryRecall`,
локальные эмбеддинги BGE-M3 (Ollama), агентный `search_memory`, извлечение фактов (`extract_facts`, Tier 0),
`episodic_log` (вся переписка) + `semantic_memory` (факты). Reflect/heartbeat-тики уже несут редкие фоновые
шаги (ApplyReflection/EvolveFascination/EvolvePhantoms) — туда же ляжет консолидация. Колбэки/grounded-
добавки (BOB-018) умеют вставлять реальные воспоминания.

## Проблема

Память **растёт безгранично и не взрослеет**: recall тяготеет к свежему (старое-но-релевантное может не
всплыть), длинная история не сжимается (нет long-term дайджестов), факты **дублируются** (`extract_facts`
плодит near-duplicate). Книжный Боб помнит **всё** и умеет **консолидировать** — это и фундамент под
непрерывность (колбэки, отношения). Сейчас этого слоя нет.

## Влияние

Память **взрослеет**: старое к месту всплывает, длинная история сжимается в дайджесты (память не пухнет +
сжатый long-term слой), факты дедуплицируются. Усиливает колбэки (BOB-018), отношения (BOB-014), общую
непрерывность. Всё **локально/приватно** (контент памяти не уходит наружу) и **не деструктивно**.

## Скоуп (3 механизма консолидации + опц.)

1. **Всплытие очень старого релевантного.** Сейчас recall смещён к свежему. Механизм иногда поднимать
   **старое-но-релевантное** («что-то напомнило») — через опцию гибрид-recall (учёт возраста как
   разнообразия) и/или существующий **колбэк-шов BOB-018** (редко, к месту). Grounded (реальное), не навязчиво.
2. **Суммаризация / дайджесты длинной истории.** Редкий фоновый шаг (на тике) сжимает **старые** эпизоды
   в **дайджесты** (новый тип записи памяти, эмбеддится, ищется наравне). **Не деструктивно:** оригиналы
   помечаются `consolidated`, не удаляются; дайджест ссылается на источники. Идемпотентно. Память не пухнет.
3. **Дедуп / слияние фактов.** Near-duplicate факты в `semantic_memory` (семантическая близость через
   эмбеддинги) **сливаются** в один. **Консервативный порог**, сохраняем provenance (источники/время),
   идемпотентно. Меньше шума в фактах.
4. **(Опц./stretch) Память-рефлексия.** Боб подмечает паттерны across памяти. Берём, только если влезает
   без риска для 1–3; иначе — выносим в отдельный пункт роадмапа.

## Не-цели (вне BOB-021)

- Внешний RAG над доками/вебом (knowledge zones) → **P3**.
- Мультимодальная память (картинки/голос).
- Кросс-устройство / облачная синхронизация памяти.
- Смена эмбеддера / vector-стора (остаются BGE-M3/sqlite-vec).
- Деструктивное удаление памяти (только пометки `consolidated`, оригиналы целы).

## Пользовательские истории

### US-1: Старое к месту всплывает
**Как** owner, **я хочу**, чтобы Боб иногда вспоминал **старое-но-релевантное**, **чтобы** память
чувствовалась глубокой, а не только «последние дни». **Приёмка:** при релевантности старое (не из топа
свежести) попадает в recall/колбэк; **реальное** (grounded); срабатывает уместно, не навязчиво.

### US-2: Длинная история сжимается
**Как** owner, **я хочу**, чтобы старая переписка **консолидировалась в дайджесты**, **чтобы** память не
пухла и был сжатый long-term слой. **Приёмка:** фоновый шаг сжимает старые эпизоды в дайджест (эмбеддится,
ищется); оригиналы помечены `consolidated`, **не потеряны**; идемпотентно (повтор не плодит дайджесты).

### US-3: Факты дедуплицируются
**Как** owner, **я хочу**, чтобы дубли фактов **сливались**, **чтобы** память Боба была чистой и точной.
**Приёмка:** near-duplicate факты сливаются по консервативному порогу; provenance сохранён; идемпотентно;
несхожие факты **не** сливаются (нет ложных слияний).

## Критерии приёмки (общие)

- [ ] 3 механизма работают **локально/приватно** (ноль внешних вызовов с контентом памяти),
      **не деструктивно**, идемпотентно, под guardrails (консервативные пороги, без runaway).
- [ ] `MemoryRecall` остаётся **drop-in** (потребители не меняются); дайджесты ищутся наравне.
- [ ] Реактив/проактив/recall (BOB-011 Ф1)/выражение (BOB-018)/эмоции (BOB-020) не сломаны.
- [ ] Тесты ≥80% на фейках (эмбеддер/LLM за портами, без сети), `ruff`/`mypy --strict` чисто, `beadloom ci` зелёный.
