# BRIEF: BOB-008 — Вариант A: typing-индикатор + быстрый rich-финал (без стриминга в группе)

> **Status:** Approved
> **Created:** 2026-06-20
> **Type:** feature

---

## Проблема

Финальный вывод: **нативный токен-стрим в групповом топике Telegram невозможен** (драфты работают только
в ЛС / Threaded Mode = темы в личке, не в группе; `editMessageText` в группе = медленно + флуд).
Доступ к Бобу — **только через группу BobNet** (ЛС закрыта authz, и так и оставляем). Значит стримить
негде → перестаём бороться.

## Решение (Вариант A, согласовано 2026-06-20)

В группе: **«печатает…» во время генерации + готовый rich-ответ одним сообщением.**

- Во время генерации ответа Боб шлёт **`sendChatAction("typing")`** в свой тред (повторять каждые
  ~4–5с, пока генерится) → пользователь видит «Bob печатает…».
- Готовый ответ — **один `send_rich_message`** в тред (`message_thread_id`): rich-блоки (заголовки/код/
  списки/цитаты) + **`RichBlockThinking`**; fallback на plain `send_message` при ошибке. (Это не драфт —
  одиночный `send_rich_message` в группе работает.)
- **Выпиливаем стриминг-машинерию:** edit-стриминг + 3с-троттл + draft-стриминг (всё неиспользуемо: в
  группе не стримим, ЛС нет). Gateway упрощается до: typing → rich-финал → plain-fallback.
- **Гибридный тиринг (flash/plus) — оставляем:** casual → flash → ответ за секунды.

UX: «печатает…» → через секунды (flash) готовый форматированный ответ. Чисто, без рывков и флуда.
