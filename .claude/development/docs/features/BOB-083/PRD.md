# PRD — Интерактивный терминал Claude Code в личке (двусторонний)

## Проблема / цель

BOB-082 дал **односторонний** лайв-стрим Claude Code в личку. Теперь — **двусторонний**: owner видит
живой поток CLI И **направляет claude в реальном времени** (отвечает на вопросы, корректирует), как в
обычной CLI-сессии, но через Telegram. По сути **stdin-мост claude ↔ Telegram**: вывод (stream-json) →
live-сообщения в личку; ввод — реплики owner'а из лички → в **открытый stdin** персистентного процесса
`claude -p --input-format stream-json --output-format stream-json` (интерактивная сессия, не
fire-and-forget как T3.B).

🔴 **Обнаруженный блокер (фундамент):** входящий DM сейчас **не доходит до Боба** — `MultiBotGateway._route`
дропает апдейты, чей `chat_id` ≠ чат-Боба (супергруппа), ещё ДО авторизации BOB-082 (multibot.py:550
«a foreign chat / DM never matches Bob's scope and is dropped here»). Без этого фикса ни интерактив, ни
даже `/code` из лички BOB-082 не работают. Чиним первым.

## Цель среза

Owner в личке открывает интерактивную claude-сессию, видит живой поток и **пишет claude напрямую**
(steer), сессия держится живой между репликами; выход/kill-switch; всё owner-only, worktree-изолировано,
main неприкосновенен (мерж по-прежнему через PR-гейт owner'а). За флагом `coder.interactive`.

## Сценарии (acceptance)

**S0 — Входящий DM доходит (фундамент-фикс).**
- Owner пишет Бобу в личку → сообщение **доходит** до Боба (роутится через multibot, авторизуется как
  owner-DM BOB-082), Боб отвечает. (Заодно чинит `/code` из лички BOB-082.)

**S1 — Открыть интерактив (главный таргет).**
- Owner в личке: `/code -i <задача>` (или явная команда интерактива) → Боб запускает персистентную
  claude-сессию в изолированном worktree, живой поток CLI идёт в личку (реюз стрима BOB-082).

**S2 — Направлять claude в реальном времени (steer).**
- Пока сессия активна, реплики owner'а в личке (не команды) идут в **stdin** claude как user-messages;
  claude реагирует, поток продолжается. Диалог с claude — двусторонний.

**S3 — Вопрос claude → owner отвечает.**
- claude задаёт вопрос/просит уточнение (stream-json событие) → всплывает owner'у в личку; ответ owner'а
  → в stdin claude. (Разрешения на правки — режим `permission_mode`, worktree-изоляция.)

**S4 — Выход / kill-switch.**
- Owner: `stop` (или выход из интерактива) → сессия завершается, процесс claude убит, worktree правки
  остаются в ветке для ревью → PR по существующему гейту (owner мержит). Личка возвращается к обычному Бобу.

**S5 — Безопасность (крит).**
- Интерактив **owner-only**, **только в личке**, за флагом `coder.interactive` (default OFF).
- 🔴 Ослабляет двойной гейт (owner направляет claude минуя план→апрув) — **осознанно**, но:
  worktree-изоляция цела (правки в `.worktrees`, никогда не main), **мерж в main только через PR-гейт
  owner'а** (main неприкосновенен), kill-switch, тайм-аут.
- Одна интерактивная сессия за раз.

## Инварианты

- **INV-0 (DM доходит).** Входящий owner-DM роутится до Боба (multibot) и авторизуется (BOB-082).
- **INV-1 (Двусторонность).** Реплики owner'а из лички → stdin живого claude; вывод claude → личка. Сессия
  персистентна между репликами (не one-shot).
- **INV-2 (Main неприкосновенен).** Правки только в изолированном worktree; мерж в main ТОЛЬКО через
  существующий PR-гейт owner'а. Двойной гейт ослаблен для правок-в-worktree, НЕ для main.
- **INV-3 (Owner-only / DM-only).** Интерактив доступен только owner'у и только в личке; за флагом; гость/
  группа — никогда.
- **INV-4 (Kill-switch).** `stop` гарантированно убивает процесс claude + чистит worktree; тайм-аут как backstop.
- **INV-5 (Режим-переключение честное).** Пока интерактив активен — личка это терминал (реплики к claude);
  выход явный, возврат к обычному Бобу. Owner всегда понимает, в каком режиме он.

## Не входит в scope (границы среза)

- **Мульти-репо / реплики / хаб** (T3.D–H) — только свой репо Боба.
- **Mini-App панель** (T3.H) — терминал в обычном чате лички, не в webview.
- **Авто-мерж / ослабление защиты main** — мерж всегда через PR-гейт owner'а.
- **Self-proposed интерактив** (Боб сам открывает) — только по команде owner'а.
- **Параллельные интерактив-сессии** — одна за раз.
