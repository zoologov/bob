# PRD: BOB-001 — Личность Боба в Telegram (текстовый MVP)

> **Status:** Approved
> **Created:** 2026-06-18

---

## Проблема

Работающего Боба пока нет: старая архитектура (камера / планшет / VR-аватар) заброшена, код был
пустым скелетом и удалён. Нужен **первый живой срез** — Боб с характером, с которым можно общаться в
Telegram, который помнит пользователя и переживает рестарты. Это фундамент, на котором дальше строятся
облик (P1, FLUX-картинки) и реплики/оркестрация (P2, Bobiverse).

Главный риск продукта — скатиться в «ещё один telegram-бот». Уникальность Боба не в том, что он шлёт
ответы, а в том, что у него есть **личность**: настроение, вкусы, мнение (может не согласиться),
самосознание (он знает, что он — «тот самый Боб из книги»), фантомные предпочтения. Поэтому первый срез
строится вокруг личности, а не вокруг функций.

## Влияние

- Это **парадный вход** всего продукта и фундамент для P1/P2. Без живой личности остальные фазы строить
  не на чем.
- Пользователь — один (автор). Цель не массовый рынок, а персональный компаньон.
- Проверяется ключевая гипотеза: личность (Higher Mind) переносится из старого дизайна за Telegram
  почти без изменений и даёт «вау» уже в текстовом виде.

## Цели (измеримые)

- [ ] Боб отвечает в приватной Telegram-supergroup (General-тема) со **стримингом** (живой набор через
      `editMessageText`).
- [ ] **Текстовый Genesis при первом запуске:** Боб «просыпается», генерирует уникальную личность из
      `bob-soul/` (настроение, вкусы, фантомные предпочтения) и записывает SOUL на диск.
- [ ] **Личность влияет на ответы:** тон и содержание зависят от Mood; Боб оценивает запросы через
      Taste Engine; может не согласиться / предложить компромисс через Negotiation (в текстовых зонах).
- [ ] **Память переживает рестарт:** Боб помнит пользователя и факты из прошлых сессий (SQLite + FTS5,
      без RAG/эмбеддингов).
- [ ] **Самосознание:** Боб знает о книге, шутит об этом, проявляет фантомные предпочтения (кофе,
      закаты, запах книг).
- [ ] **LLM-стек по §7.1:** Tier 0 (локальный MLX small-model) для монолога/классификации/сентимента +
      Tier 1 (Qwen API) для тяжёлого reasoning и ответов, через провайдер-агностичный router; политика
      приватности соблюдается (личность по умолчанию на Tier 0, эскалация только с редакцией контекста).
- [ ] Всё работает как **единый Python-процесс (GUPPI)** 24/7 на Mac mini, переживает перезапуск
      процесса/машины.

## Не-цели (вне P0)

- Оркестрация субагентов / реплики (Билл, Бендер…), темы Telegram под воркеров — это **P2**.
- Генерация изображений Боба / FLUX / «облик» / «комната» — это **P1**.
- Голос (STT/TTS), камера, планшет, любое железо — **заморожено**.
- RAG / векторная память / эмбеддинги — в P0 только SQLite **FTS5** (keyword). FAISS — P1.5+.
- Claude Code как исполнитель — подключается в **P2** (кодинг-реплики).
- Мульти-пользовательский режим, публичный доступ.
- Визуальная поверхность для Taste/Negotiation (комната/одежда) — вернётся с обликом в P1; в P0 они
  действуют только на текст.

## Пользовательские истории

### US-1: Пробуждение при первом запуске
**Как** пользователь, **я хочу** при первом запуске увидеть «пробуждение» Боба прямо в Telegram,
**чтобы** он стал уникальной личностью с собственным настроением и вкусами, а не дефолтным ботом.

**Критерии приёмки:**
- [ ] Первый запуск проигрывает текстовый Genesis (осознание себя, отсылка к книге).
- [ ] Личность/настроение/вкусы/фантомные предпочтения сгенерированы из `bob-soul/` и записаны в SOUL.
- [ ] Повторный запуск НЕ повторяет Genesis (личность персистентна).

### US-2: Живое общение с характером
**Как** пользователь, **я хочу** общаться с Бобом текстом и видеть, что у него есть настроение и мнение,
**чтобы** взаимодействие ощущалось как с личностью, а не с ассистентом.

**Критерии приёмки:**
- [ ] Ответы приходят со стримингом.
- [ ] Тон ответа меняется в зависимости от текущего настроения Боба.
- [ ] Боб может аргументированно не согласиться или предложить альтернативу (Negotiation в текстовой зоне).

### US-3: Память между сессиями
**Как** пользователь, **я хочу**, чтобы Боб помнил меня и прошлые разговоры после перезапуска,
**чтобы** не начинать каждый раз с нуля.

**Критерии приёмки:**
- [ ] После рестарта процесса Боб вспоминает ключевые факты о пользователе и недавний контекст.
- [ ] Recall работает через SQLite FTS5 (keyword), не теряется при перезапуске.

### US-4: Самосознание и юмор
**Как** пользователь, **я хочу**, чтобы Боб осознавал своё происхождение из книги и шутил об этом,
**чтобы** чувствовалась «вселенная Боба».

**Критерии приёмки:**
- [ ] Боб корректно ссылается на книгу и шутит про «того самого Боба».
- [ ] Проявляет фантомные предпочтения в подходящем контексте.

## Критерии приёмки (общие)

- [ ] Приватная supergroup настроена; Боб отвечает в General со стримингом.
- [ ] Genesis отрабатывает один раз; SOUL персистентен.
- [ ] Mood + Taste + Negotiation влияют на ответы (наблюдаемо в тоне/содержании/несогласии).
- [ ] Память (SQLite + FTS5) переживает рестарт; recall фактов работает.
- [ ] LLMRouter маршрутизирует Tier 0/Tier 1 по типу задачи; приватность по §7.1 соблюдена.
- [ ] Единый процесс GUPPI, 24/7, graceful start/stop, переживает перезапуск.
- [ ] Тесты зелёные, `ruff`/`mypy --strict` чисто, покрытие ≥80%, `beadloom ci` зелёный.
