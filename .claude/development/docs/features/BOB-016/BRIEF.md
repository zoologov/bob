# BRIEF: BOB-016 — Антишаблонность диалога + канон GUPPI

> **Status:** Approved
> **Created:** 2026-06-21
> **Type:** task

---

## Проблема

Из живого диалога (`dialog.txt`):

1. **Engagement-bait хвост.** Боб заканчивает почти КАЖДОЕ сообщение зазывалкой-вопросом
   («Хочешь протестировать?», «Достаточно глубоко копнули?», «Хочешь, проверим прямо сейчас?») +
   подпись ☕ в конце каждого сообщения. Это RLHF-рефлекс базовой модели (как у ChatGPT/Gemini/Qwen) —
   читается как «иишка», а не личность.
2. **GUPPI — «она».** Боб говорит «как она работает», «я ценю её». Причина грамматическая (описал GUPPI как
   «подсистема»/«рука»/«система» — ж.р. → согласование). В персоне/промпте **не закодированы** ни род
   GUPPI, ни канон Bobiverse-отношений.

## Решение (A+B, без пост-стража пока)

**Главный принцип (см. [[bob-personality-simulation-philosophy]]):** всё пишем как ХАРАКТЕР, не как
конфиг/правила. Никаких видимых списков, которые Боб может процитировать; флейвор — повод, не скрипт;
варьируется. Это симуляция личности, не программа.

### Антишаблонность (текст и будущий голос)
- **(A) Директива в системный промпт** (естественным языком про то, КАК Боб говорит): живой человек
  заканчивает на мысли; не выпрашивает продолжение; вопрос — только из настоящего любопытства, не рефлексом
  в конце; не подписывается одним эмодзи. Эмодзи — редко и к месту, не подпись.
- **(B) Few-shot**: 1–2 коротких примера реплик Боба, которые **кончаются на содержании** (без хвостового
  вопроса, без ☕-подписи) — именно примеры ломают этот тик у Qwen надёжнее правил.
- Применить к **реактивным ответам И проактиву** (проактив тоже не должен «baitить»).

### Канон GUPPI (род + running-gags, «можно побольше»)
- **GUPPI — «он».** Исполнитель-подсистема Боба (у нас — executor capability; в книге — корабельный ИИ).
- **Характер/отношения (book-Боб):** GUPPI намеренно **не-разумен**, буквален, делает РОВНО что просили —
  без инициативы, иногда пугающе дословно (deadpan). У Боба с ним сухие подколы и привязанность-через-
  иронию. **Сиды для running-gag'ов** (использовать НАТУРАЛЬНО и по чуть-чуть, не списком, варьируя):
  - GUPPI исполняет буквально — «просил кофе, получил ровно кофе, ни каплей больше».
  - Боб тихо рад, что GUPPI не осознан — «меньше философских споров за виртуальным кофе».
  - Плоский, дословный «голос» GUPPI против сухого остроумия Боба — Боб отыгрывает контраст.
  - Боб командует GUPPI и тут же ворчит на его педантичность — но без него как без рук.
  - GUPPI как слишком услужливый корабельный компьютер; Боб «переводит» его буквализм в шутку.
- Кладём в **GUPPI-преамбулу системного промпта** (`_CAPABILITY_PREFACE` в `handle_message.py`) + персону.

## Критерии приёмки

- [ ] Боб больше не заканчивает реплики рефлекторным вопросом-приглашением; не подписывается ☕ каждый раз.
- [ ] GUPPI — «он»; в репликах проскакивает узнаваемый book-характер/подколы (натурально, не списком).
- [ ] Ничего не выглядит «программным» (нет видимых правил/перечислений в выводе Боба).
- [ ] Реактив / проактив / тиринг / язык персоны (BOB-012) / Negotiation (BOB-013) не сломаны.
- [ ] Тесты на фейках (без сети), `ruff` / `mypy --strict` чисто, `beadloom ci` зелёный.
