# RFC: BOB-013 — Глубина личности (Negotiation-врезка + Само-эволюция)

> **Status:** Approved
> **Created:** 2026-06-21

---

## Обзор

Замыкаем два разомкнутых контура личности, выявленных аудитом (`PERSONALITY-DEPTH-AUDIT.md`):

1. **Negotiation-врезка** — готовый `Negotiation.decide(zone, conviction) -> Stance`
   (`domain/personality/negotiation.py`) подключается к генерации ответа: зона темы + убеждённость → стойка
   → **директива в системный промпт**. Боб перестаёт быть безусловно угодливым.
2. **Само-эволюция** — `ReflectTick` после генерации рефлексии **применяет** её к душе: чистый доменный
   `TasteEvolution.reinforce` сдвигает/укрепляет taste-ось (+ опц. mood-baseline), результат **персистится**
   через `SoulStore` (round-trip уже готов: `_load_soul` читает обратно). С жёсткими guardrails.

Всё локально, детерминированно где можно, инъекция портов, TDD на фейках.

## Технический контекст

### Ограничения
- Python 3.12+, DDD/Clean (домен чист, без I/O), `uv`, `mypy --strict`, `ruff`, cov ≥80%, TDD.
- Инъекция `Clock`/портов; детерминизм доменных функций (без скрытого LLM, где можно эвристикой).
- Не ломать: реактивный чат, проактив (BOB-010), память (BOB-011), тиринг, authz, язык персоны (BOB-012).
- `SOUL` иммутабелен (`with_*` возвращает копию); персист — через существующий `SoulStore.write_json`.

### Затрагиваемые области
`domain/personality/{negotiation.py (готов), taste.py (+геттер conviction), soul.py (+with_taste/with_baseline),
taste_evolution.py (новый)}`, `application/usecases/{handle_message.py, heartbeat.py}`, новый use-case
`ApplyReflection`, `domain/ports.py` (порт `ZoneClassifier`; SoulStore-write уже есть), `app.py` (сборка).

## Фаза 1 — Negotiation-врезка

### Швы (из аудита)
- `handle_message._decide` (224-260) и `_assemble_shareable_context` (297-325) — сюда уже кладётся
  taste-вердикт темы; добавляем стойку.
- `_SYSTEM_PROMPT` (79-82) — сейчас безусловно «warmly and concisely»; стойка модифицирует тон.

### Решение
1. **Геттер убеждённости** на `TasteEngine`: `conviction_for(topic) -> float` (находит релевантную ось;
   нет оси → `0.0`). Чистый, детерминированный.
2. **Порт `ZoneClassifier`**: `classify(topic, *, taste_verdict, conviction) -> NegotiationZone`.
   - **Дефолт-реализация `TasteZoneClassifier`** (эвристика, без сети, детерминированная): тема, на которую
     у Боба есть выраженный вкус (|value| высок) → **BOB_PERSONAL** (его территория мнений); явные маркеры
     логистики/быта пользователя (расписание, громкость, «когда/во сколько») → **USER_DOMAIN**; иначе
     **SHARED**. Порог/словарь — в реализации, не в домене.
   - Порт абстрактный → позже свопаемо на Tier-0 LLM-классификатор без изменения потребителей (рекоменд.
     апгрейд в Ф2 BOB-014, не сейчас — ради цены/детерминизма).
3. **Решение стойки**: `zone = classifier.classify(...)`; `stance = Negotiation().decide(zone,
   conviction=conviction_for(topic))`.
4. **Стойка → директива промпта** (карта, не новый LLM-вызов):
   - `CONCEDE` → «это территория пользователя — спокойно прими его выбор».
   - `AGREE` → «у тебя нет сильной позиции здесь — поддержи, без навязывания».
   - `PROPOSE_ALTERNATIVE` → «у тебя есть своё мнение и убеждённость — **аргументируй и предложи своё**,
     уважительно, без агрессии и без капитуляции».
   - Директива **дополняет** «warmly», не заменяет тепло (анти-цель VISION: не yes-man, но и не грубиян).
5. Только когда есть таргетная тема/вкус (как сейчас вердикт). Нет темы → поведение как до BOB-013.

### Тесты (фейки)
- `conviction_for`: ось найдена/не найдена.
- `TasteZoneClassifier`: вкус-тема → BOB_PERSONAL; логистика → USER_DOMAIN; нейтральное → SHARED.
- Интеграция `handle_message` со стаб-классификатором: HATE+high conviction в BOB_PERSONAL → в промпте
  директива PROPOSE_ALTERNATIVE; USER_DOMAIN → CONCEDE-директива; «warmly» сохранён.

## Фаза 2 — Само-эволюция

### Швы (из аудита)
- `ReflectTick.run` (`heartbeat.py:142-163`) — единственный сайд-эффект `save_episode`; добавляем **после**
  сейва эпизода шаг применения к душе.
- Живой `SOUL` после boot меняется только через `with_mood`; добавляем `with_taste`/`with_baseline`.
- Персист: `SoulStore.write_json` (round-trip готов — `_load_soul` читает обратно при старте).

### Решение
1. **`domain/personality/taste_evolution.py`** (чистый, без I/O) — `reinforce(axis, *, nudge) -> TasteAxis`:
   - `value' = clamp(value + α · nudge · (1 − conviction), −1, 1)` — **при высокой убеждённости сдвиг
     меньше** (анти-runaway: устоявшееся мнение тяжелее сдвинуть).
   - `conviction' = clamp(conviction + β · |nudge| · (1 − conviction), 0, 1)` — убеждённость растёт
     **асимптотически** к 1 (затухающий прирост, не перескок).
   - Константы `α`, `β` малы (напр. α=0.15, β=0.10) → эволюция **медленная, на горизонте многих рефлексий**.
2. **`SOUL.with_taste(updated_axes)`** и **`with_baseline(delta)`** — иммутабельные обновления (как
   `with_mood`); `experience_count` инкрементируется здесь.
3. **Use-case `ApplyReflection`** (application): вход — текст рефлексии + текущая `SOUL`; шаги:
   парс рефлексии в **сигнал** (какая ось, знак/сила nudge — Tier 0, дёшево, или эвристика по тексту) →
   `reinforce` затронутых осей → `with_taste`(+опц. `with_baseline` мелкой дельтой настроения) →
   возврат новой `SOUL` + флаг «изменилось».
4. **Врезка в `ReflectTick`**: после `save_episode(reflection)` → `ApplyReflection` → если изменилось,
   `SoulStore.write_json(new_soul)` и обновить live-state.

### Guardrails (жёстко, проверяются тестами)
- **Границы:** `conviction ∈ [0,1]`, `value ∈ [-1,1]` — `reinforce` всегда clamp.
- **Анти-runaway:** множитель `(1−conviction)` → чем увереннее Боб, тем меньше дрейф; убеждённость не
  перескакивает 1.
- **Идемпотентность:** каждая рефлексия применяется **не более раза** — маркер `last_evolved_ref`/processed-id
  в состоянии; повторный прогон того же тика — no-op (тест на двойной вызов).
- **Малый шаг/тик:** одна рефлексия двигает ось на ограниченную дельту (α мало); никаких скачков.
- **Гейт релевантности:** применяем только при распознанном сигнале (нет сигнала → no-op, без шума).

### Тесты (фейки: фейк-роутер + фейк-SoulStore)
- `reinforce`: ось усиливается; при высокой conviction сдвиг **меньше**, чем при низкой; границы держатся.
- `ApplyReflection`: распознанный сигнал → ось изменилась + `experience_count++`; нет сигнала → no-op.
- `ReflectTick`: при изменении вызывается `write_json`; **двойной прогон идемпотентен**.
- Регрессия: `mood_drift`/`inner_monologue` тики и реактив не затронуты.

## Рассмотренные альтернативы
- **Zone через Tier-0 LLM на каждый ответ** — отложено: цена/детерминизм; порт оставляет апгрейд открытым.
- **Эволюция «в лоб» (value += δ без (1−conviction))** — отвергнуто: runaway-дрейф, личность «уезжает».
- **Эволюция на каждый реактивный ответ** — отвергнуто: слишком быстро/шумно; привязываем к рефлексии (редкий тик).
- **Хранить эволюцию отдельно от SOUL** — отвергнуто: SOUL — единый источник; round-trip уже готов.

## Риски

| Риск | Вер. | Влияние | Митигация |
|---|---|---|---|
| Дрейф личности «вразнос» | Med | High | `(1−conviction)`-затухание, малые α/β, гейт, тесты-границы |
| Двойное применение рефлексии | Med | Med | Идемпотентный маркер + тест двойного прогона |
| Negotiation делает Боба грубым | Low | Med | Директива дополняет «warmly»; PROPOSE_ALTERNATIVE = уважительно |
| Парс рефлексии в сигнал шумит | Med | Low | Гейт релевантности (нет сигнала → no-op); Tier 0 дёшев |
| Зона неверно классифицирована | Med | Low | Эвристика-дефолт консервативна (нейтральное → SHARED→AGREE); порт свопаем |
