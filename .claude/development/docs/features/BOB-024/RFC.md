# RFC: BOB-024 — «Краткость по запросу» (длина = answer-demand x интерес x настроение)

> **Status:** Approved
> **Created:** 2026-06-24

---

## Обзор

Боб получает **осмысленную длину ответа**: чистый сигнал **answer-demand** (сколько
развёрнутости объективно требует само сообщение) объединяется с **интересом** (BOB-014 .2a)
и **настроением/аппетитом** (BOB-020 / .2a) в решение о **многословии** (`Verbosity`). Из него
собирается **сильная директива длины + few-shot коротких ответов**, которые **бьют
verbosity-байес Qwen** (мягкого `form_hint` BOB-018 для этого мало). Опциональный лёгкий
**страж длины** ужимает переразвёрнутый ответ на простой вопрос. Всё — «как характер»: длина
реплики Боба перестаёт быть константой. Композируется поверх BOB-023 (та решает *отвечать ли*,
эта — *насколько коротко*).

## Технический контекст

### Ограничения
- Python 3.12+, DDD/Clean: детектор/решение — **чистый домен** (без I/O, детерминированно;
  любая стохастика — через инъектированный seeded-RNG); композиция в `app.py`; инъекция
  Clock/RNG/портов. **TDD на фейках через `.venv/bin/pytest`** (uv run висит), `mypy --strict`,
  `ruff`, cov >=80%.
- Не ломать: BOB-018 (`ExpressionPlan`/`FormHint`/REACT_ONLY), BOB-014 .2a (аппетит/interest/
  TERSE), BOB-023 (адресность/SILENT), BOB-020 (mood/off-days), память/проактив/тиринг/perception.

### Затрагиваемые области
`domain/personality/brevity.py` (new — answer-demand + verbosity), `domain/personality/voice.py`
(новые `brevity_directive` + few-shot, как anti-bait), `application/usecases/handle_message.py`
(вычислить demand+verbosity, прокинуть в сборку system-prompt; опц. страж длины),
`infrastructure/config/loader.py` + `app.py` (секция `brevity.*`).

---

## Предлагаемое решение

### (1) Сигнал answer-demand (чистый домен)
- `domain/personality/brevity.py`: `AnswerDemand ∈ {LOW, MEDIUM, HIGH}` + чистая
  `classify_answer_demand(*, text) -> AnswerDemand`:
  - **LOW** — простой/закрытый вопрос или короткая реплика: да/нет, «ты тут?», «во сколько?»,
    «получилось?», подтверждение/факт-чек, очень короткий текст без вопросительных слов
    развёрнутости.
  - **HIGH** — открытый/глубокий запрос: вопросительные слова «почему/как/зачем/что
    думаешь», явные «расскажи/объясни/сравни/подробнее/разверни», много-частный вопрос,
    просьба мнения/рассуждения.
  - **MEDIUM** — всё прочее (обычная реплика без явного сигнала в обе стороны).
  - Лёгкая лексическая эвристика (рус+eng), детерминированная, без I/O. Порог/словарь —
    константы модуля; тонкая настройка через `brevity.*`.

### (2) Решение о многословии (чистый домен)
- `Verbosity ∈ {TERSE, NORMAL, EXPANSIVE}` + чистая
  `decide_verbosity(*, demand, interest, mood_valence, engagement, form_hint, roll, thresholds)`:
  - База — `demand` (LOW→TERSE, HIGH→EXPANSIVE, MEDIUM→NORMAL).
  - **Интерес повышает** (US-4): высокий `interest` может поднять TERSE→NORMAL / NORMAL→EXPANSIVE
    даже на скромном вопросе (увлёкся) — порог высокий, изредка seeded.
  - **Настроение/аппетит понижают** (US-3): плохой `mood_valence` / низкий `engagement`
    (BOB-014 .2a TERSE/DECLINE) урезают на ступень даже содержательное.
  - **`form_hint` (BOB-018)** входит как мягкий вход (настроенческий хинт длины), а не отдельная
    директива — BOB-024 владеет финальной длиной, устраняя двойные сигналы.
  - **Анти-обрубок (US-5):** прямой содержательный запрос (HIGH demand) к owner не опускается
    ниже NORMAL независимо от настроения — Боб не «отшивает» односложно.

### (3) Краткость БАЙЕСОМ — директива + few-shot
- `voice.brevity_directive(verbosity)` — **сильная** инструкция (не мягкий намёк): для TERSE —
  «ответь одной фразой, без вводных/преамбул/списков; как живой человек в чате»; EXPANSIVE —
  разрешение развернуться; NORMAL — нейтрально.
- `voice.brevity_few_shot(verbosity)` — для TERSE подмешивает **few-shot примеры** «простой
  вопрос → короткий ответ» (тем же механизмом, что anti-bait few-shot в `_SYSTEM_PROMPT`), —
  именно примеры перебивают verbosity-prior модели сильнее любой директивы.
- Встраивается в `_system_prompt_for` рядом с существующими директивами (заменяет нынешний
  мягкий form_hint-путь).

### (4) Опциональный страж длины
- После генерации: если `demand == LOW` и ответ длиннее порога (`brevity.length_guard.max_chars`)
  — **лёгкое** ужатие (взять первую законченную мысль / мягкая обрезка по предложению), без
  перегенерации. По умолчанию **выключен/консервативен** (механизм — байес из (3); страж — лишь
  страховка). Управляется `brevity.length_guard.*`.

### Композиция
`handle_message`: perceive(BOB-019) → addressivity(BOB-023) → [ENGAGE] → demand+verbosity(BOB-024)
→ system-prompt += brevity_directive + few-shot → compose → [опц. страж] → reply. Гость-инвариант
(BOB-019) и SILENT (BOB-023) не затрагиваются — BOB-024 влияет лишь на длину *выбранного* ответа.

## Guardrails (под тестами)
- **Простой/закрытый вопрос → TERSE-директива + few-shot** (US-1); ответ коротким байесом.
- **Открытый/глубокий → EXPANSIVE/NORMAL** (US-2) — не урезается.
- **Плохое настроение/низкий аппетит → ступень вниз** (US-3), но HIGH-demand owner не ниже NORMAL.
- **Высокий интерес → ступень вверх** (US-4), редко/seeded, не монолог.
- **Анти-обрубок (US-5):** прямой содержательный запрос owner не получает односложный «отшив».
- Детектор/решение чисты и детерминированы (стохастика seeded); «как характер», не конфиг.

## Рассмотренные альтернативы
- **Только жёсткий `max_tokens`** — отвергнуто: режет на полуслове, не «характер», ломает US-2/4.
- **Усилить лишь текстовую директглву без few-shot** — отвергнуто: Qwen переигрывает директиву
  длиной; примеры — главный рычаг против verbosity-prior.
- **LLM-классификатор answer-demand на каждый ход** — отвергнуто для v1: цена/недетерминизм;
  берём лексическую эвристику (порт абстрактен — усилить позже).
- **Пост-резюмирование длинного ответа второй генерацией** — отвергнуто как основной путь:
  цена/латентность; оставляем лишь лёгкий опц. страж.

## Риски
| Риск | Вер. | Влияние | Митигация |
|---|---|---|---|
| Боб рубит там, где нужен развёрнутый ответ | Med | High | demand HIGH→EXPANSIVE; анти-обрубок owner; тесты US-2/US-5 |
| Few-shot ломает тон/язык | Low | Med | примеры в стиле Боба (рус), короткие; тесты на язык/тон |
| Verbosity дерётся с form_hint (двойные директивы) | Med | Med | form_hint — вход в decide_verbosity; одна финальная директива |
| Эвристика answer-demand ошибается на пограничных | Med | Low | MEDIUM по умолчанию; интерес/настроение сглаживают; порог в конфиге |
