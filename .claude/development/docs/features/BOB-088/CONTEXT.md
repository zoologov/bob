## Где мы

Работа взята 2026-08-15, сразу после BOB-098 (PR #133). Ветка `features/BOB-088` от `dfd2018`.

Спека написана **при взятии в работу**, и это себя оправдало: описание беады от 2026-08-03
устарело по трём пунктам из трёх. Один барьер исчез сам, два оказались неверны, зато открылись
два новых — и один из них P0 про живую систему (`bob-l3t`).

## Проверенные факты (перемерены 2026-08-15)

- `bd` в отдельном рабочем дереве **работает** и пишет в основной трекер. Барьера нет.
- Пер-действенного гейта claude в headless-режиме **нет**: пишущий Bash проходит молча.
- `--allowedTools` **расширяет**, `--disallowedTools` **сужает** (на уровне шаблона команды).
- Отказ даёт событие `system/permission_denied`; сессия продолжает жить.
- Запрет инструмента целиком **обходится другим инструментом** (запретили `Bash` — сделал `Write`).
- `coder.isolated_clone` и `coder.allow_bypass` в живом конфиге **отсутствуют** → оба OFF →
  сегодня работа идёт в linked worktree репозитория owner'а, без push-барьера.

## Решения

| # | Решение | Почему |
|---|---|---|
| Р-1 | Граница — **структурная** (клон без кредов), не список команд | Проба E: список обходится другим инструментом |
| Р-2 | Push-барьер **всегда**, а не только под `allow_bypass` | Сейчас страховка включается вместе с ослаблением, которое её обесценивает |
| Р-3 | Гибрид реализуется **denylist'ом необратимого**, а не allowlist'ом разрешённого | Наблюдаемое поведение CLI |
| Р-4 | «Доразрешить» на месте нельзя — только повторный заход `--resume` | Ограничение CLI, называем честно, `bypassPermissions` не берём |
| Р-5 | Вход — **живая речь**; слеши работают молча | Решение owner'а 2026-08-15, см. BOB-101 |

## Ловушки этого места

- Тест на фейке доказывает контракт фейка: для `claude`, `git` и subprocess нужен прогон на
  настоящем инструменте (§0.3 п.4). Вся эта спека держится на таких прогонах.
- Гейт, читающий текст, наследует его иллюзии (§0.3 п.12, дополнен вчера): у гарда бывает второй
  вход, и саботаж обязан **обманывать** гард, а не только ломать предмет.
- Отгрузка без активации — не возможность. Проверяя, что фича есть, ищи **включённый флаг и живой
  прогон**, а не запись в конфиге-примере.
