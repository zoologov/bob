## Сейчас

**Срез 3 (`bob-c3r.3`) сделан dev-волной, ждёт верификации координатора** (не закоммичен).
Каждый спавн живого терминала несёт узкий ЗАПРЕТ необратимого (`git push`, `git remote`,
`git reset --hard`, `rm`, `gh pr merge`, `curl`, `wget`) — без флага, выключить нечем.
Упёршись, Боб СПРАШИВАЕТ владельца в личку живой речью (голос Боба, без кнопок и слешей),
а на «да» возвращается в ту же нить `claude` повторным заходом `--resume` с точечным
разрешением РОВНО одной команды на ОДИН заход. Разрешение рутины конвейера (`git
status/add/commit`, `uv run pytest/ruff/mypy`, `bd`, `beadloom`) — за owner-флагом
`coder.pipeline_tools` (default OFF), и его придётся включить вместе с `pipeline_prompt`:
замер показал, что без него встроенный гейт CLI останавливает работу уже на `git add`.

- 🔴 **Срез 3, главная находка — RFC-факт «пер-действенного гейта нет» УСТАРЕЛ.** На
  claude 2.1.233 встроенный гейт отказывает САМ и без нашего списка: `git push`, `git
  reset --hard`, `git remote add`, `git add`, `git commit`, `python3 -c`, `sh -c …`,
  `bash script.sh`, `chmod` — все получают «This command requires approval». А `rm -rf`
  ВНУТРИ рабочего каталога проходит молча. Два следствия: (а) наш denylist уникально
  ценен там, где встроенный молчит (необратимое внутри рабочего места); (б) утверждение
  ТЗ «pytest/ruff/mypy/bd/git add/commit едут сами» НЕВЕРНО — без `--allowedTools`
  конвейер встанет на первом коммите. Проверено, что лечится: с разрешением рутины тот же
  прогон делает коммит, 0 отказов. Приоритет замерен: ЗАПРЕТ СИЛЬНЕЕ РАЗРЕШЕНИЯ.
- 🔴 **Срез 3, дыра в самом шаблоне из ТЗ:** `Bash(rm -rf:*)` НЕ ловит `rm -fr` —
  в прогоне каталог был УДАЛЁН. В списке стоит широкий `Bash(rm:*)`; живой смоук написан
  именно на `rm -fr`, поэтому краснеет ровно на «правильной по спеке» подмене.
- Срез 3: «доразрешить на месте» невозможно (права — аргументы спавна), и это названо в
  докстроках и в реплике Боба, а не обойдено `bypassPermissions`. Механика возвращения
  измерена целиком: `--resume <id>` + точное `--allowedTools "Bash(<команда>)"` + кадр
  «повтори ту команду» → модель повторила её, push реально прошёл.

## Ловушка на виду

Три эпика подряд ловили «документ обещает больше, чем проверка держит». Здесь тот же класс
нашёлся в **живом свойстве безопасности**: защита была объявлена дефолтом и ни разу не проверена
прогоном. Срез 3 обязан не создать четвёртую иллюзию — denylist называется страховкой, границей
называется клон.
