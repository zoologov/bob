# PRD: BOB-051 — «Единая публичная память закрытой группы»

> **Status:** Approved
> **Created:** 2026-06-30
> **Feature:** BOB-051 · Тир-1 «Личность/человечность» · «единый разум» · эпик `bob-051`

---

## Контекст

В BOB-045 (память по персоне) non-owner recall заскоуплен по `sender_id` ради приватности, а гость
(BOB-019) получает «ноль памяти + голос настороженного незнакомца». Это дало **«расщеплённую память»**:
разговаривая с не-owner, Боб теряет доступ к своему же **общему знанию**.

## Проблема (живой баг — диалог с Норманом)

Норман (друг owner'а в группе) спросил «что такое T3 / ждёшь ли переход на t3 roadmap» (#1520/1524/1526) →
Боб ушёл в **«Терминатор 3» / «ТЗ» / новый фреймворк** — потому что в нити с Норманом **нет** общего знания
о том, что такое T3 roadmap (его обсуждал только Владимир). Owner'у пришлось вручную релеить (#1521). Боб
выглядит как **человек с амнезией по собеседникам** — а он ОДИН разум.

## Цель

Боб — **единый разум**: его знание/память доступны в разговоре с **любым участником** группы. Группа
Bobiverse — **закрытое публичное пространство** (инвайт по ссылке, модерируемо) → память Боба **единая для
всех**. Защита приватности — не на памяти, а на **инструментах/внутрянке** (отдельно, BOB-052).

## Пользовательские истории

- **US-1 (единое знание).** Норман спрашивает про roadmap/архитектуру/проект → Боб отвечает из своего
  общего знания (как Владимиру), а не «впервые слышу / это фильм».
- **US-2 (полноценный собеседник).** Участник группы получает **нормального Боба** (память + голос), а не
  «настороженного незнакомца с нулём памяти».
- **US-3 (общая память пополняется всеми).** Разговоры всех участников — часть общей памяти Боба (публичны),
  Боб помнит, что обсуждал с Норманом, и может это использовать.
- **US-4 (непрерывность по персоне цела).** Боб по-прежнему знает, КТО пишет, и держит нить с каждым
  (BOB-049/050) — единая память не ломает атрибуцию/continuity.
- **US-5 (🔴 граница приватности держится).** Инструменты/внутрянка/owner-данные **не** раскрываются
  неавторизованным без разрешения — это НЕ память, это BOB-052. В BOB-051 они остаются гейтом как сейчас.

## Критерии успеха

- Боб использует **единое знание** с любым участником группы (баг Нормана закрыт); нормальный голос.
- Память пополняется ходами всех участников (публичная общая).
- **🔴 Инструменты/внутрянка/owner-данные НЕ ослаблены** (остаются гейтом — BOB-052/authz); per-person
  атрибуция/нить целы.
- Без регрессий BOB-045/049/050; «единый разум», не амнезия.

## Объём

**В объёме (только память):**
- **Снять per-person скоуп recall** (`_scoped_recall`) → recall единый для любого участника группы.
- **Снять гостевые memory-ограничения** (BOB-019): recall/history больше не пустые для не-owner;
  **stranger-voice** заменить на нормального Боба для участников закрытой группы.
- **Fact-extraction со всех групповых ходов** (публичная общая память), не только owner.
- Per-person нить/атрибуция (BOB-049/050) — оставить.

**Вне объёма:**
- **Инструменты/capabilities, owner inner-life add-ons (внутрянка), owner-данные** — остаются гейтом; их
  раскрытие неавторизованным с разрешения owner — **BOB-052** (отдельная фича).
- **Личка/DM-приват** Боба — будущее (там появится настоящий приват).

## Связи и принципы

- Снимает над-ограничение **BOB-045** (per-person recall scoping) и memory-часть **BOB-019** (гостевые
  ограничения). Сохраняет authz BOB-019 для tools/внутрянки. Реюз handle_message/recall. Близнец/преемник —
  **BOB-052** (разрешение на привилегированное). Север: `bob-personality-simulation-philosophy` («единый
  разум, не амнезия»), `bob-social-identity-strangers`.
