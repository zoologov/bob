# RFC: BOB-051 — «Единая публичная память закрытой группы»

> **Status:** Approved
> **Created:** 2026-06-30
> **PRD:** `.claude/development/docs/features/BOB-051/PRD.md`
> **Решения (утв.):** голос не-owner = полностью нормальный · разовый аудит хранимых фактов перед живым
> прогоном (операционно).

---

## Идея решения

Сейчас один флаг `is_guest` (BOB-019 `Trust.GUEST`) гейтит и ПАМЯТЬ, и ПРИВИЛЕГИИ (инструменты/внутрянка).
BOB-051 **расцепляет их**: память (recall/история/голос/fact-extraction) становится **единой/публичной** для
всех участников закрытой группы; привилегии (capabilities, owner inner-life add-ons, owner-данные) **остаются
гейтом** (их разрешение неавторизованным — BOB-052). Боб — один разум: знание доступно с кем угодно в группе.

## Что снимаем (память → публичная/единая)

В `src/bob/application/usecases/handle_message.py`:
1. **`_scoped_recall` (~2302) — убрать per-person скоуп.** Recall возвращается единым для ЛЮБОГО собеседника
   (owner и не-owner) — общее знание Боба доступно всем. (`recalled_excluding_reflections` BOB-033 остаётся
   — рефлексии не копируются в reply; это про дословное копирование, не про знание.)
2. **Recall/история не пустые для не-owner.** Сейчас гость → `recalled=[]`, history через
   `_replay_person_history(is_guest=True)` урезана. → не-owner участник получает recall (единый) + свою
   per-person нить (continuity).
3. **Stranger-voice → нормальный голос** для участников закрытой группы (`stranger_directive` не добавляется;
   Боб общается как с человеком, а не настороженно). Закрытая группа = приглашённые = доверенные социально.
4. **Fact-extraction со всех групповых ходов** (~1381 `if is_guest: skip`) → ход любого участника пополняет
   общую память (публичная). Owner-факты больше не «audience-redacted» от участников группы (память публична).

## Что ОСТАЁТСЯ гейтом (НЕ трогаем — это BOB-052/authz)

🔴 `is_guest` (или authz) по-прежнему блокирует для неавторизованных:
- **Capabilities / tool-loop** — не-owner не запускает инструменты (BOB-052 даст flow «спросить разрешение»).
- **Owner inner-life add-ons** (`leak_inner_life` / callback / fascination) — **внутрянка** Боба (его приватная
  внутренняя жизнь) не раскрывается неавторизованным. Остаётся owner-only.
- **Owner-команды/данные** (`/code`, `/goals`, config, owner-данные) — authz как сейчас.

То есть `is_guest` сохраняется как флаг **привилегий**, но перестаёт резать **память/голос**.

## Per-person continuity (цела)

`_replay_person_history` (нить с человеком) + атрибуция (кто пишет, BOB-049/050) остаются — это про
**continuity/кто**, не про знание. Единое recall + per-person нить сосуществуют: Боб знает, что обсуждал
именно с Норманом (нить), И помнит общее знание (recall).

## Слои (DDD)

- **application (`handle_message`):** расцепить memory-использования `is_guest` от привилегий-использований;
  recall единый; не-owner получает recall+историю+нормальный голос; fact-extraction для всех.
- Domain/infra recall — без изменений (скоуп был в application).

## 🔴 Безопасность (инвариант после расцепления)

- **Память публична** в пределах закрытой группы — это решение owner (закрытая модерируемая группа).
- **Привилегии целы:** не-owner НЕ получает инструменты, внутрянку (inner-life), owner-команды/данные без
  авторизации/разрешения. Тест-инвариант: не-owner ход → recall+история+нормальный голос ЕСТЬ, но
  tool-loop НЕ запускается, `leak_inner_life`/callback/fascination НЕ добавляются, `/code`/`/goals` отказ.

## Риски и митигации

- **Чувствительные owner-факты в recall** → станут видны участникам группы (память публична). Митигация:
  перед живым прогоном — разовый просмотр хранимых фактов на наличие genuinely-приватного (если есть —
  прун/в будущую DM-личку); внутрянка (inner-life) и так остаётся гейтом. Это осознанное решение owner
  («группа публична; приват — позже в личке»).
- **Регрессии BOB-045/049/050** → per-person нить/атрибуция/реакции целы (трогаем только memory-скоуп/голос).
- **Случайно ослабить привилегии** → review строго проверяет, что tools/inner-life/owner-данные НЕ
  ослаблены (только память/голос).

## Открытые решения (под утверждение)

1. **Голос для не-owner:** полностью нормальный Боб (как с owner по тону) для участников группы — **рекомендую**
   (закрытая группа = доверенные). Альтернатива — лёгкая социальная теплота-но-без-фамильярности к новым;
   но это усложняет. Рекомендую: нормальный голос.
2. **Чувствительные факты:** разовый аудит хранимых фактов перед живым прогоном (операционно), без кода —
   **рекомендую**. Согласовать.
