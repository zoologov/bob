# BRIEF: BOB-047 — Диапазон внутренней жизни (рефлексии не залипают в один регистр)

> **Status:** Approved
> **Created:** 2026-06-27
> **Type:** feature · продолжение BOB-033 (эмоц. саморегуляция) · эпик `bob-047`

---

## Проблема (живой срез)

Последние 8 рефлексий Боба — все в ОДНОМ регистре («сердце колотится / предвкушение / вот-вот прыжок»),
`mood=excited`. Это зеркало старой застрявшей грусти — теперь застрял-в-возбуждении. Не по-человечески:
у живого человека внутренняя жизнь варьируется (возбуждение, тихое довольство, любопытство, лёгкая
тревога, воспоминание, бытовое замечание).

**Корень:** (1) grounding рефлексии НЕ фильтрует `event_type` → подаёт прошлые РЕФЛЕКСИИ как «recent
moments» → модель мимикрирует свой же регистр (само-подкормка, тот же механизм, что у грусти —
[[bob-tone-dynamics]]); (2) угол рефлексии всегда один (нет seeded-разнообразия режима мысли). Палитра
`LIVING_REFLECTION_EXAMPLES` сама по себе ок, но статична и узковата.

## Решение (структурно, как BOB-033 — не скрипт)

1. **Заземлять на НЕ-рефлексии.** Grounding-«moments» рефлексии собирать из недавних НЕ-reflection
   эпизодов (сообщения/действия/реальные события), исключив рефлексии. Рефлексии остаются для ДЕДУПА
   (BOB-026), но не подаются как few-shot grounding → разрыв само-подкормки регистра.
2. **Разнообразие угла (seeded-RNG).** Ротация «режима» внутренней мысли по тику: воспоминание / ощущение
   / взгляд вперёд / бытовое замечание / благодарность / тихое довольство / лёгкая тревога / любопытство.
   Детерминированно (seeded-RNG, варьируется по тику), mood-честно (низкое допускается, не форсим радость),
   не скрипт конкретной фразы — угол задаёт ТИП мысли, модель наполняет.
3. **Расширить палитру** `LIVING_REFLECTION_EXAMPLES` по регистрам (возбуждение И тихое довольство И
   любопытство И лёгкая грусть) — чтобы few-shot сам нёс диапазон.
