# PRD — Dev-интроспекция: git-история + работа с трекером (read-only)

## Проблема (живой кейс из чата, 2026-07-31)

Владелец пытался обсудить с Бобом инцидент с кодером и что по нему починили — Боб упёрся в стену на
каждый запрос заглянуть в код/историю/задачи. Дословно из `episodic_log`:

```
21:15  Владимир: А ты глянь код, что было исправлено, как тебе?   Боб: Вова, я же не телепат…
21:16  Владимир: Посмотри последние закрытые задачи                Боб: Это не закрытые, Вова. Это «Ready»…
21:18  Владимир: А глянь историю в git                            Боб: Вова, я не могу просто «глянуть историю»
21:18  Владимир: Посмотри 10 последних коммитов                    Боб: Вова, я не могу просто «посмотреть»…
21:20  Владимир: надо git подкрутить и трекер задач                Боб: Согласен
```

**Корень:** у Боба есть навигация по файлам (BOB-067: `list_dir`/`find_file`/`read_code`), но нет
инструментов заглянуть в **историю git** и в **трекер задач (beads)**. Поэтому разговор о том, «что мы
сделали/починили/в каком состоянии работа», он не может **заземлить** — только отнекивается. При этом
интроспектор git технически есть (`RepoIntrospector.code_history`, BOB-038), но не проброшен в
чат-петлю как разговорный инструмент.

Это второй enabler из обсуждения self-model (2б): без него даже автобиография ([[bob-079-autobiography]])
упирается в слепоту к собственной истории правок.

## Цель среза

Дать Бобу **read-only разговорные инструменты dev-интроспекции**, чтобы он мог сам, по просьбе,
заглянуть и связно рассказать:
- **git-история:** последние коммиты / лог (что и когда менялось).
- **трекер (beads):** списки задач по статусам (открытые / в работе / закрытые), детали задачи,
  комментарии к задаче.

Результат инструмента возвращается модели, и Боб отвечает **своими словами** (сводка), а не дампом.

## Сценарии (acceptance)

**S1 — Последние коммиты (главный git-таргет).**
- Владимир: «глянь последние 10 коммитов»
- Боб (вызвав git-инструмент): «Последний — [BOB-080] ростер комнаты; до него автобиография [BOB-079],
  мерж #111… Хочешь по какому-то подробнее?»

**S2 — Закрытые/открытые/в работе задачи.**
- Владимир: «посмотри закрытые задачи» / «что у нас в работе?»
- Боб (вызвав tracker-инструмент): перечисляет реальные беады нужного статуса своими словами (не путает
  «Ready» с «закрыто» — как это случилось в живом чате).

**S3 — Детали задачи и комментарии.**
- Владимир: «что там по BOB-076?» / «покажи комментарии к той задаче про кодер»
- Боб (вызвав tracker-инструмент): пересказывает суть задачи и ключевые комментарии/чекпоинты.

**S4 — Заземление разговора о работе (стык с автобиографией).**
- Владимир: «помнишь инцидент с кодером — что мы по нему сделали?»
- Боб: присваивает своё (BOB-079) + подтягивает факт из трекера/гита: «…мы это загейтили — вон, [BOB-076]
  nl_autostart за флагом».

**S5 — Честность/безопасность.**
- Инструмент ничего не нашёл → Боб честно «не нашёл/пусто», без выдумки.
- Инструменты **только читают**: Боб не коммитит, не пушит, не создаёт/не закрывает задачи через них.
- В выводе не утекают секреты (санитайз-бэкстоп, урок [[bob-067-repo-navigation]]).

## Инварианты

- **INV-1 (Read-only).** Инструменты git/tracker только читают: никаких мутаций (commit/push/checkout,
  `bd create`/`update`/`close`). Мощные автономные действия — не через эти инструменты (урок
  [[bob-076-coder-runaway]]).
- **INV-2 (Заземление, не дамп).** Вывод инструмента возвращается модели; Боб отвечает связной сводкой
  своими словами.
- **INV-3 (Без секретов).** Вывод прогоняется через санитайз-бэкстоп (редакция токенов/секретов) — урок
  BOB-067 (живой смоук поймал утечку .env).
- **INV-4 (Авторизация).** Dev-интроспекция доступна **владельцу и явно авторизованным** (KNOWN);
  **гостю — отказ** (инструментов не получает). Это ровно существующий гейт tool-loop (`is_guest`:
  авторизованный ход получает инструменты, гость — нет) — новую authz-грануляцию НЕ вводим.
- **INV-6 (Источник трекера).** Данные трекера — через **`bd` CLI в read-only** (allowlist только
  read-подкоманд: `list`/`show`/`comments`, таймаут, санитайз), как существующий `subprocess`-интроспектор.
- **INV-5 (Честность).** Пусто/не найдено → честный ответ, без фабрикации коммитов/задач.

## Не входит в scope (границы среза)

- **Любая запись** в git или трекер (commit/push/`bd create/update/close`) — INV-1; за пределами среза.
- **Coder/автономное исполнение** (BOB-039) — это про запуск правок, не про чтение; не трогаем.
- **Глубокая аналитика/дашборды** по трекеру — здесь базовые списки/детали/комментарии, не отчётность.
- **Проактивное** самостоятельное лазанье в git/трекер без повода — инструменты вызываются по запросу/
  необходимости в ходе, не в фоне.
