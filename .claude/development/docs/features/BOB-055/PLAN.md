## Критерии приёмки (из PRD)

- `web_search` завершается на медленных (1–2 мин) поисках (стриминг), без ложных обрывов на ~30с.
- Как только Боб инициирует поиск — owner сразу видит живую реплику «ищу…», затем финальный ответ.
- 🔴 Реальный сбой → честный нотис без выдумки (инвариант BOB-053 не ослаблен).
- Реплика «ищу…» звучит естественно и по-разному (seeded-выбор из набора).

## Риски

- Парсинг SSE Responses API → терпимый парс, тест на реалистичный поток; нет финала → raise.
- Анонс декоративен → тест «сбой gateway не ломает ход».
- Двойной анонс на ретраях → приемлемо (редко).
