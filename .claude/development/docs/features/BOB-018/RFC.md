# RFC: BOB-018 — «Выражение» (BOB-010 Фаза 2 · T1.1)

> **Status:** Approved
> **Created:** 2026-06-21

---

## Обзор

Боб получает **спонтанную выразительность** в диалоге через 4 grounded-элемента, всё **как характер, не
конфиг** (решает состояние/настроение + seeded-RNG; флейвор — через voice/few-shot; контент — из реальной
памяти/рефлексий). Ключевая идея: перед составлением ответа считается **план выражения** (ExpressionPlan),
который выбирает *режим* (полноценный ответ / краткая реакция) и *добавки* (протекающая внутренняя жизнь /
колбэк / подсказка формы). Добавки **строго grounded**: нет реального материала → элемент не срабатывает
(no-op), Боб ничего не выдумывает.

## Технический контекст

### Ограничения
- Python 3.12+, DDD/Clean (домен чист, иммутабелен), инъекция `Clock`/**seeded RNG**/портов, TDD на фейках
  (без сети), `mypy --strict`, `ruff`, cov ≥80%.
- Не ломать: anti-bait/voice (BOB-016), язык (BOB-012), Negotiation-директиву (BOB-013), проактив (BOB-010),
  память (BOB-011), тиринг, authz/topic-scope.
- **Анти-тик:** элементы срабатывают **редко и по состоянию/релевантности**, не в каждом сообщении.

### Затрагиваемые области
`domain/personality/expression.py` (новый — план выражения, чистый), `domain/ports.py` (порт `MessageReactor`;
метод «недавняя рефлексия»), `application/usecases/handle_message.py` (врезка плана + добавок),
`infrastructure/telegram/` (реализация `set_message_reaction`), `infrastructure/persistence/` (выборка
свежей реальной рефлексии), `domain/personality/voice.py` (директива переменной формы), `config` (частоты).

## Предлагаемое решение

### План выражения (ядро)
- **`domain/personality/expression.py`** — чистая функция `decide_expression(mood, signals, *, rng, freqs)
  -> ExpressionPlan`. `ExpressionPlan`: `mode` ∈ {`REACT_ONLY`, `REPLY`} + флаги `leak_inner_life`,
  `callback`, + `form_hint` (terse/normal/expansive). Решение **детерминированно от mood + сигналов +
  seeded-RNG** (как `select_reply_tier`): напр. низкая энергия/короткое входящее → выше шанс `REACT_ONLY`/
  terse; частоты `leak/callback` — малые, из конфига. **Не LLM** (дёшево, тестируемо). _Q1._

### (1) Реакции — `REACT_ONLY`
- Порт **`MessageReactor.react(chat_id, message_id, emoji)`**; реализация в telegram-gateway через
  **`set_message_reaction`** (подтв.: есть в aiogram). Эмодзи — из **малого mood→emoji набора** в пределах
  **стандартного reaction-set Telegram** (кастом-эмодзи — premium, не сейчас). _Q2._
- При `mode=REACT_ONLY` Боб ставит реакцию (или краткий ack) **вместо** полного ответа; LLM-вызова на ответ
  нет (дёшево). `REPLY` остаётся дефолтом, когда есть что сказать.

### (2) Протекающая внутренняя жизнь — `leak_inner_life`
- Порт/метод **«последняя реальная рефлексия»** (из `episodic_log`, `event_type` ∈ {reflection,
  inner_monologue} — их уже пишет BOB-012, по-русски/grounded). При флаге — текст рефлексии кладётся в
  compose-промпт как «то, о чём ты ловил себя на мысли» (естественно, по-русски). **Нет рефлексии → no-op.**

### (3) Переменная форма — `form_hint`
- Директива в `voice.py` (стиль BOB-016): «форма/длина варьируются по настроению — иногда коротко, иногда
  развёрнуто; не одна рамка» + 1 few-shot. `form_hint` из плана подаётся в compose как мягкий ориентир
  (terse/normal/expansive). **Дополняет** anti-bait, не заменяет.

### (4) Колбэки — `callback`
- При флаге — **гибрид `MemoryRecall`** (BOB-011) по текущей теме → если есть **сильный реальный** прошлый
  момент, кладётся в compose как «можешь к месту вспомнить это (реальное)». **Слабый/пустой recall → no-op**
  (анти-конфабуляция, как в BOB-012).

### Врезка в `handle_message`
1. Считать `ExpressionPlan` (mood + signals + rng).
2. `REACT_ONLY` → `MessageReactor.react(...)`, ответ не генерим.
3. Иначе собрать compose-контекст как сейчас + по флагам добавить inner-life / callback / form_hint.
4. Сгенерить ответ (тиринг/voice/язык/Negotiation — без изменений).

## Guardrails (под тестами)
- Элементы **редкие** (частоты малые, из конфига) и **по состоянию** — не в каждом сообщении (анти-тик).
- inner-life/callback **только из реальных данных** — нет материала → no-op (никакой выдумки).
- **Детерминизм:** seeded-RNG + инъекция Clock → тесты воспроизводимы.
- Совместимость: anti-bait/voice (BOB-016), язык (BOB-012), Negotiation (BOB-013) — компонуются, не ломаются.
- `REACT_ONLY` уважает authz/topic-scope; реакция best-effort (ошибка API → лог, не падаем).

## Рассмотренные альтернативы
- **Решать выражение через LLM на каждое сообщение** — отвергнуто: цена/недетерминизм; берём heuristic+RNG.
- **«Печатать» внутреннюю жизнь всегда** — отвергнуто: тик/назойливость; делаем редко и grounded.
- **Сами генерим «воспоминание»** — отвергнуто: конфабуляция; только реальный recall (как BOB-012).

## Риски
| Риск | Вер. | Влияние | Митигация |
|---|---|---|---|
| Элементы навязчивы (тик) | Med | Med | Малые частоты из конфига + по состоянию + тесты на «редко» |
| Конфабуляция в leak/callback | Med | High | Только реальные данные; нет материала → no-op |
| Реакции выглядят случайными | Low | Low | mood→emoji маппинг; форма дополняет, не доминирует |
| set_message_reaction ограничения (set/премиум) | Low | Low | Стандартный reaction-set; best-effort + фоллбэк на краткий ack |

## Открытые вопросы
| # | Вопрос | Предложение |
|---|--------|-------------|
| Q1 | Решатель выражения: heuristic vs Tier-0 | Heuristic + seeded-RNG (дёшево/детерминир.); Tier-0 позже при нужде |
| Q2 | Эмодзи реакций | Малый mood→emoji набор в стандартном reaction-set; кастом (premium) — позже |
| Q3 | Частоты leak/callback/react | Малые дефолты в конфиг (тюнинг), per-persona |
