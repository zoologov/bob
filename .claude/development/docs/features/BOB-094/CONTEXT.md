## Ловушки этого места

- 🔴 Секрет через shell/лог — утечка. Значения только у owner'а в GitHub Secrets; workflow не эхает.
- 🔴 Объявление рестарта не должно БЛОКИРОВАТЬ shutdown: сеть легла → молча выходим, не виснем.
- 🔴 «Оглох»-сигнал даёт Боб, который оглох, — сам о себе в Telegram написать не может. Полноценный
  внешний алерт — ОТДЕЛЬНО, здесь только лог/статус. Не делать полу-решение, выдающее себя за алерт.
- Тест на фейке для SSH/systemd доказывает контракт фейка — деплой проверяется живым прогоном у
  owner'а по runbook (§0.3 п.4); в репозитории — `bash -n`, идемпотентность, ядра под mutation.
- Отгрузка без активации — не возможность (§0.3 п.10 + урок BOB-088): «workflow есть» ≠ «деплой
  поехал»; критерий приёмки — реальная выкатка на VPS, а не наличие yml.
