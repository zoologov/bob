# PRD — Ростер комнаты: Боб помнит, кто рядом и кто недавно зашёл

## Проблема (живой кейс из чата, 2026-07-31)

Владелец спросил Боба открыто, про состав группы — Боб не смог вспомнить участников, пока имена не
назвали вслух. Дословно из `episodic_log`:

```
21:24:07  Владимир: Боб, о чём размышляешь? И, кстати, как тебе новые ребята в чате?
          Боб: Р…                              ← размыто, не понял про кого
21:24:24  Владимир: Боб?           Боб: Тут.
21:25:01  Владимир: Лиля и Паша    Боб: А, те самые.   ← «включился» ТОЛЬКО на имена
21:25:32  Владимир: Как тебе они?  Боб: Нормальные. Паша лаконичен, Лиля — по делу…
```

Ключевой нюанс: **память есть, припоминания нет**. В `first_impression` оба участника лежат с момента
их прихода (Павел — 13:00, Лиля — 14:59), с именем, `first_seen_at` и заметкой. Но recall у Боба **чисто
лексический** (FTS по тексту входящего сообщения): фраза «новые ребята в чате» не пересекается по словам
с «Лиля»/«Паша» → не всплывает ничего. Назвали имена — FTS зажёгся — «А, те самые».

**Корень:** у Боба нет **ростера** — ощущения состава комнаты как объекта. Человек на «как тебе
новенькие?» мгновенно перебирает «кто недавно зашёл». У Боба нет ни ростера, ни retrieval-пути
«перечисли недавно встреченных»; есть эпизоды и семантика по словам — и всё.

Это бьёт по north star «максимально человечен»: живой участник группы держит в голове, кто рядом и кто
новичок, и может об этом говорить без подсказок.

## Цель среза

Боб держит **социальный ростер** знакомых участников (кто есть, кто недавно зашёл) и умеет **припомнить
его по социальному поводу** — на открытый вопрос о людях в чате называет их сам, без подсказки имён, и
отделяет **новеньких** от давно знакомых.

## Сценарии (acceptance)

**S1 — Припоминание состава по социальному поводу (главный таргет).**
- Владимир: «как тебе новые ребята в чате?»
- Боб: «Лиля и Паша-то? Лиля фронт пишет, по делу; Паша лаконичный. Норм зашли.»
- (Боб сам называет недавних участников — БЕЗ подсказки имён.)

**S2 — Отделение новичков от старожилов.**
- На вопрос про «новеньких» Боб поднимает именно **недавно** зашедших (Лиля/Паша, дни назад), а не
  владельца или давних знакомых (Norman, Алексей — недели/месяцы назад).

**S3 — Знакомство новичка (не молчать при появлении).**
- Новый человек впервые пишет в группу → Боб фиксирует его в ростере и, если уместно по такту
  присутствия, отмечает появление (пересекается с engagement [[bob-078-dialogue-quality]] — здесь не
  дублируем, а опираемся: ростер даёт «этот — новичок»).

**S4 — Честность (без выдумки участников).**
- Если в ростере нет никого недавнего, Боб не выдумывает людей, а честно говорит, что новеньких не
  припоминает. Ростер отражает **реально встреченных** (тех, у кого есть `first_impression`), а не
  фантазию.

## Инварианты

- **INV-1 (Ростер из реальных встреч).** В ростер попадают только участники, кого Боб реально встречал
  (есть `first_impression`/relationship); никаких выдуманных людей.
- **INV-2 (Припоминание по социальному поводу).** На открытый вопрос о людях/новеньких состав всплывает
  БЕЗ необходимости называть имена в сообщении (не завязано на лексический FTS-матч).
- **INV-3 (Новизна по времени).** «Новенький» определяется по **давности первой встречи** (recency
  `first_seen_at`), а не по имени/трасту; порог новизны разумный и настраиваемый.
- **INV-4 (Точечность, не флуд).** Ростер поднимается на релевантный социальный повод (вопрос о людях/
  появление новичка), а не подмешивается в каждый ход — «не баржить» сохранено ([[bob-072-stream-read]]).

## Не входит в scope (границы среза)

- **Полноценное отслеживание присутствия/членства в реальном времени** (кто «в сети», кто вышел из
  группы) — Telegram не даёт надёжного сигнала; ростер строится из **уже накопленных** `first_impression`/
  relationship, а не из live-членства.
- **Переработка engagement-правил BOB-078** — S3 опирается на них, не переписывает.
- **Изменения authz/приватности** — ростер не расширяет доступ; уважает существующие visibility/trust.
- **Проактивное «первым заговорить с новичком»** без запроса — за пределами среза (пересекается с
  proactivity governance); здесь — припоминание по поводу + пометка новичка для engagement.
