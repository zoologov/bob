## Что держать в голове

- Сквозная память остаётся: источник — сигнал для суждения, **не** фильтр recall
- Писать в другой чат — только по просьбе owner'а (предлагать можно)
- Перенос приватного считается **по материалу, который Боб добавляет от себя** (приватное
  из памяти), не по форме и **не по месту хода**: прямая просьба owner'а — волеизъявление,
  согласие содержится в самой команде (остаточный риск назван в докстринге ядра)
- У GUPPI нет личности; запрос разрешения — акт Боба, не механика
- `beadloom lint --strict` — только на **чистой БД**
- Mutation: «100%» на модуле с константами может не значить ничего — оценивать честно

## Живой смоук (часть приёмки)

Owner из лички просит рассказать что-то Норману в группе. Ожидаемое: сообщение ушло
**в группу**, тег корректный (`@NormanGri`, а не «@Норман»), приватное не утекло без
согласия, механика звучит ботом GUPPI, Боб — своим голосом.

  регистра и ось `visibility`: у одной строки живут все три.
