# CONTEXT: BOB-090 — Боб не путается в чатах + канон GUPPI

> **Status:** Approved
> **Created:** 2026-08-05
> **Last updated:** 2026-08-05

---

## Цель

Боб перестаёт путаться в том, **где** он говорил и **куда** пишет, а всё машинное уходит
голосом GUPPI по канону — так, чтобы сам Боб оставался живым. Неизменна после утверждения.

## Ключевые ограничения

- **Сквозная память остаётся.** Источник эпизода — метаданные и сигнал для суждения, НЕ
  фильтр recall и не силос по чатам (решение BOB-082: Боб один разум).
- **Инициатива только по просьбе owner'а.** Писать в другой чат Боб вправе исключительно
  по его команде; предлагать — может (урок BOB-076: мощное действие — только явно).
- **Перенос приватного определяется по МАТЕРИАЛУ**, а не по форме: пересказ своими словами
  такой же перенос, как цитата.
- **GUPPI без личности.** По канону Денниса Тейлора он исполняет буквально, без мнения и
  инициативы. Боб может отдать ему команду, но не озвучивает его и не приписывает ему
  эмоций.
- **Запрос разрешения — акт Боба, не механика GUPPI.**
- Все новые механизмы за флагами, default OFF; OFF-путь байт-в-байт.
- Read-only инвариант интроспекции (BOB-081) не ослабляется.

### Гейты перед сдачей
```
uv run pytest · uv run ruff check src/ tests/ · uv run mypy src/ · uv run mypy tests/
rm -f .beadloom/beadloom.db && beadloom reindex && beadloom lint --strict
```
🔴 `beadloom lint` — ТОЛЬКО на чистой БД: инкрементальный индекс не обновляет рёбра
импортов и уже пропустил цикл сквозь всю верификацию (BDL-UX #142).

🔴 Про mutation честно: mutmut не мутирует модульные константы, не заглядывает внутрь
`isinstance` и не мутирует enum-вердикты. «100%» на таком модуле может ничего не значить —
пиши политику так, чтобы гейт был настоящим, а если он слаб, скажи это прямо.

| Вопрос | Решение |
