# RFC: BOB-010 — Эпик «Живой Боб»: человечность

> **Status:** Approved
> **Created:** 2026-06-20

---

## Обзор

Per-persona **`ProactivityEngine`** в `application`, питаемый heartbeat: каждый тик считает **порыв**
(urge) из состояния Higher Mind + тишины + салиентности свежей рефлексии + циркадного ритма, обновляет
**социальную энергию**, и **стохастически** (seeded RNG) решает «заговорить ли», под **governance-
потолками**. При срабатывании — дешёвый **Tier-0-гейт** («есть ли что сказать и что?») → компоновка
(тиринг) → постинг в Bob/32 через существующий gateway (typing + reply). Поверх — **выражение** (реакции,
переменная форма, протекающая внутр. жизнь, колбэки) и **состояние отношений/эмоций/увлечения**. Всё —
per-persona (реплики наследуют), детерминизм через инъекцию `Clock`/seed. Поведение = **выражение уже
построенного субстрата** (mood/taste/negotiation/память/heartbeat), не cron/шаблоны.

## Технический контекст

### Ограничения
- Python 3.12+, asyncio, DDD (`infrastructure → application → domain`), `uv`, `mypy --strict`, `ruff`,
  покрытие ≥80%, TDD. **Инъекция `Clock` + seeded RNG** (детерминизм времени/стохастики). Секреты из env.
- Реактивный чат (BOB-001..009) и authz/routing не ломать. Где LLM — реалистичные reasoning-формы.
- Дёшево: порыв/governance — формула без LLM; Tier-0-гейт только при срабатывании; Tier-1 — только на реплике.

### Затрагиваемые области
`application/proactivity/*` (новый движок/urge/governance), `application/runtime/heartbeat` (новый тик),
`domain/personality` (urge/energy/relationship/fascination — value objects + порт стора),
`infrastructure/persistence` (per-persona состояние), `infrastructure/llm` (гейт + компоновка через
router/тиринг), `infrastructure/telegram/{gateway,guppi}` (reactions, переменная форма, `/quiet`/`/wake`),
`app.py` (сборка).

## Предлагаемое решение

### Фаза 1 — Проактивность (drive-движок)

- **`UrgeModel`** (`domain`, чистая функция): `urge(mood, silence, salience, time_of_day_local,
  social_energy) -> float[0..1]`. Слагаемые: настроение (arousal/openness/social), тоска (растёт с тишиной),
  салиентность свежей reflect-мысли, циркадная база (по локальному времени из `Clock`).
- **`SocialEnergy`** (`domain` value + стор): копится в тишине, тратится на реплику, частично
  восполняется ответом owner → естественный cooldown.
- **Стохастика:** `urge → p(speak)` (монотонная мапа, напр. логистическая) + seeded RNG-сэмпл на тике.
  Нет фиксированного ритма.
- **`Governance`** (`application`, потолки-вето): quiet-hours **жёсткий пол** (локальное время) · анти-спам
  max/окно · мин-гэп · cooldown после сообщения owner · **owner-mute** (персист-флаг). Veto перекрывает порыв.
- **`ProactiveTick`** (heartbeat): обновить energy → urge → governance → сэмпл; если fire → **Tier-0-гейт**
  (`есть ли что сказать сейчас и о чём?`, дефолт «skip») → компоновка (тиринг: обычно flash, plus для
  содержательного) → постинг в Bob/32 → потратить energy, выставить `last_spoke_at`.
- **Owner-команды** `/quiet` (+ опц. `/quiet 2h`), `/wake` — обрабатывает **GUPPI** (Main), только owner;
  переключают персист-флаг проактивности.
- **Персист (per-persona):** `social_energy`, `last_spoke_at`, `last_user_msg_at`, `proactivity_enabled`.

### Фаза 2 — Выражение (живая фактура)

- **Реакции:** gateway `set_message_reaction` (Telegram `setMessageReaction`); решатель (mood + контент)
  иногда реагирует 👍❤️😂 **вместо** текстового ответа.
- **Протекающая внутр. жизнь:** гейт/компоновка иногда поднимает свежую **reflect-мысль** heartbeat
  («пока тебя не было, думал о…») — она уже пишется в `episodic_log` (tag heartbeat/reflection).
- **Переменная форма:** «шейпер» сообщения по настроению — одно-словные/чанк в 2–3 коротких/абзац; gateway
  умеет слать несколько коротких сообщений с микропаузами.
- **Паузы + колбэки:** переменная «пауза на подумать» (инъекция `Clock`) перед проактивом; компоновка
  использует recall (колбэки в прошлое) + детектор **брошенных тем** (незакрытый вопрос Боба/owner).

### Фаза 3 — Отношения и эмоции (per-persona состояние)

- **`Relationship` (близость):** аккумулятор, растущий с позитивным взаимодействием → влияет на тон
  (формальность → интимность). Персист.
- **Эмоции в две стороны:** расширяем входы mood — тепло/холод/**отсутствие** owner двигают настроение
  (долгая тишина → спад/тоска; тёплое → подъём; сухое → лёгкий спад). Mood-движок уже есть.
- **Мнения/несогласие:** компоновка опирается на **Negotiation/Taste** (уже есть) — позиция, споры, не yes-man.
- **Не-вечно-услужлив:** настроение/энергия красят полезность — «не знаю», уязвимость, off-day (низкий
  mood-день → суше/замкнутее).
- **`Fascination` (увлечение):** состояние «во что Боб залип», дрейфует со временем (heartbeat) и всплывает.

### Сквозное
- Всё **per-persona** (стор по persona) → реплики наследуют. `Clock`/seed инъектируются везде.
- Поведение рождается из Higher Mind/памяти/heartbeat; анти-цели (фейк-опечатки/вечный позитив/yes-man) — запрещены.

## Рассмотренные альтернативы
- **Плоский rate-limit как двигатель** — отвергнуто (механистично, «пахнет ботом»); лимиты — только потолок.
- **Cron/расписание проактива** — отвергнуто: фиксированный ритм неестественен; берём drive+стохастику.
- **LLM на каждом тике** — отвергнуто (дорого): порыв — формула, LLM только при срабатывании.
- **Глобальное (не per-persona) состояние** — отвергнуто: ломает модель реплик Bobiverse.

## Риски

| Риск | Вер. | Влияние | Митигация |
|---|---|---|---|
| Проактив спамит/рандомен | Med | High | Гейт-самоограничение + governance-потолки + дефолт молчать; лог urge-решений; live-тюнинг |
| Стоимость убегает | Low | High | Tier-0-гейт только при fire; бюджет-кап; дефолт silent |
| Недетерминизм времени/рандома в тестах | Med | Med | Инъекция `Clock` + seeded RNG везде |
| «Человечность» субъективна | High | Med | Итеративный live-тюнинг с owner; наблюдаемость; фазовая поставка |
| Reactions/мульти-сообщения — специфика Telegram | Low | Low | Тесты на фейках; fallback на обычный reply |

## Открытые вопросы

| # | Вопрос | Предложение |
|---|--------|-------------|
| Q1 | Мапа `urge→p` + каденс проверки | Логистическая `urge→p`; проверка на heartbeat-каденсе (~30с), но fire редок за счёт модели |
| Q2 | Модель гейта/компоновки | Гейт = Tier-0 (flash); компоновка = тиринг (flash/plus по содержательности) |
| Q3 | Дефолты governance | quiet ~23:00–09:00 локально (мягко через циркаду + жёсткий пол); анти-спам ~неск./сутки — это ПОТОЛОК, модель держит ниже; тюним live |
| Q4 | Эволюция relationship/fascination | Простые аккумуляторы + дрейф, инъекция seed; тюним live |
| Q5 | Реакция vs ответ | Дешёвая эвристика + mood; иногда только реакция на «ack»-сообщения |
