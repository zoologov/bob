# BRIEF — Боб нарративит инструмент вместо вызова (recall poisoning)

## Проблема (живая, owner)

На «загляни в `for-bob/presentation`…» (путь реально существует, под корнем репо → guard пускает) Боб
выдал **нарратив**: «GUPPI, загляни… Он уже пошёл… Ждём отчёт», **не вызвав** list_dir/read_code. Реального
результата нет. Повторяющийся симптом.

## Корень (подтверждён живыми смоуками против Qwen)

Tool-loop исправен: `ToolLoop.run` — `if not result.tool_calls: return result.text`. Инструмент-вызов, если
эмитится, выполняется; нарратив-контент при tool_call отбрасывается (`_assistant_turn` структурный, BOB-069).
НО:
- На **чистом** промпте Qwen **корректно вызывает** `list_dir` (и thinking on/off).
- Стоит подсунуть в контекст **прошлые «GUPPI пошёл…» ответы Боба** (осевшие в истории от ранних до-BOB-067/069
  инцидентов) — модель **дословно их мимикрирует**, и при сильном отравлении **вообще не эмитит tool_call** →
  `not result.tool_calls` → нарратив возвращается → отправляется/персистится → **пере-отравляет** историю.
  Само-усиливающийся цикл. Это [[bob-tone-dynamics]] recall-poisoning/few-shot-mimicry, но про поведение с инструментами.
- Усугубляет `_CAPABILITY_PREFACE` («Эти возможности GUPPI исполняет для тебя») — поощряет антропоморфный
  GUPPI-нарратив.

## Решение (структурное, само-исцеляющее — БЕЗ прунинга истории)

### Fix 1 — ужесточить промпт (`voice_composer.py _CAPABILITY_PREFACE` + сборка system_prompt)
Явно и императивно: **НИКОГДА не описывай, что GUPPI „пошёл/заглянет/ищет/перебирает" — это НЕ ответ.**
Если нужен инструмент — **ВЫЗОВИ его (tool_call) и дай РЕАЛЬНЫЙ результат**. Нарратив о намерении без
реального результата запрещён. (Считать это анти-few-shot правилом, перебивающим отравленные примеры.)

### Fix 2 — backstop в tool-loop (`tool_loop.py run`)
Если ход вернулся БЕЗ tool_calls, но текст выглядит как **нарратив-намерение инструмента** (эвристика:
упоминание GUPPI/«загляну/пошёл/перебир/ищу файл» + отсутствие реального содержания) — **один повторный
заход** с жёстким системным нюджем «Не описывай намерение — вызови инструмент СЕЙЧАС». Bounded (1 ретрай),
чтобы не зациклить. Если после ретрая всё ещё нарратив — вернуть как есть (не хуже текущего). Так реплики
становятся реальными ответами → новые правильные ответы разбавляют старый яд (де-poison не нужен).

## Проверка (обязательно)
🔴 **Живой смоук против реального Qwen с ОТРАВЛЕННЫМ контекстом** (прошлые «GUPPI пошёл…» ходы в истории) +
новым промптом/backstop: убедиться, что теперь модель ВЫЗЫВАЕТ инструмент (или backstop дожимает), а не
возвращает нарратив.
