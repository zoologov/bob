## Решения по ходу

- **Чиню по семантике движка, а не по догадке.** Сначала прочитал, как beadloom
  сопоставляет цель (`fnmatch` по пути импорта без суффикса), и только потом выбирал форму
  глоба. Иначе получился бы ещё один фикс по форме.
- **Компактная форма `X*` вместо пары правил.** Пара точных правил (`X` и `X/*`) удвоила бы
  YAML; `X*` короче, но шире, поэтому ширина закрывается **сборочной проверкой по реальному
  дереву**, а не обещанием в комментарии. Тот же приём, что уже живёт в этом файле
  (`_assert_internals_covered`).

## Решения по ходу (дополнено)

- **Продовый код не тронут ни строкой** — `git diff src/` пуст. Работа целиком в правилах,
  генераторе и тестах, как и должно быть у починки гарда.
- **🔴 Маскировка пайпом поймана в третий раз за сессию.** Проверяя кусачесть сборочной
  проверки, я сначала прочитал `EXIT=0` — это был код `tail`, а не генератора. Честный замер
  дал 1. Вывод на будущее: код возврата снимать ТОЛЬКО без пайпа.
