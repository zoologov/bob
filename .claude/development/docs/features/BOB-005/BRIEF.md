# BRIEF: BOB-005 — Фикс: сообщения в теме Боба теряются (роутинг привязан к боту-доставщику)

> **Status:** Approved
> **Created:** 2026-06-19
> **Type:** bug

---

## Проблема

Live: **GUPPI отвечает, а Боб молчит** в своём топике. DEBUG-лог:
```
dropping cross-bot duplicate (-1004372947307, 41) via bob
dropping cross-bot duplicate (-1004372947307, 42) via bob
```
- Сообщения **приходят** (оба бота-админа видят их).
- Кросс-бот дедуп `(chat_id, message_id)` выкидывает копию, доставленную **через бота-Боба** (копия
  через GUPPI пришла первой и «выиграла» дедуп).
- «Выжившая» (GUPPI-доставленная) копия **НЕ доходит до пайплайна Боба** (нет ни одной строки
  `MessageReceived`/`HandleMessage`).

**Корень:** маршрутизация **привязана к боту-доставщику**. Обычное авторизованное сообщение в теме
Боба, пришедшее первым через GUPPI, обрабатывается в GUPPI-контексте (где для не-команды/авторизованного
= no-op) → проглатывается; а копия, пришедшая через бота-Боба (которая запустила бы пайплайн), дедупится.
Итог: Боб не видит сообщения. GUPPI работает, потому что его кейсы (команды/reject) совпадают с
доставщиком-GUPPI.

## Решение

**Развязать маршрутизацию от бота-доставщика.** После кросс-бот дедупа центральный роутер должен
маршрутизировать **единственную выжившую копию по СОДЕРЖИМОМУ** (chat/topic/команда/authz), а НЕ по
identity доставившего бота:
- сообщение в теме Боба (`chat==chat_id` И `thread==bob.topic_id`) + авторизован → **пайплайн Боба**
  (ответ ботом-Бобом), независимо от того, какой бот его доставил;
- команда в General / неавторизован → GUPPI;
- остальное → игнор.

Дедуп по `(chat_id, message_id)` остаётся (обработка один раз), но «победитель» дедупа роутится по
содержимому, а не по доставщику.

## Критерии приёмки

- [ ] Сообщение в теме Боба, доставленное **первым через бота-GUPPI**, всё равно запускает пайплайн
      Боба ровно один раз и получает ответ ботом-Бобом.
- [ ] Дедуп по `(chat_id, message_id)` сохранён (нет двойной обработки).
- [ ] Команда/неавторизованный → GUPPI (как было); единый authz-гейт цел.
- [ ] Регресс-тест на фейках: msg в теме приходит через guppi-бота → Bob pipeline invoked; через оба
      бота → ровно один раз.
- [ ] Существующие тесты зелёные; ruff + `mypy --strict` чисто; `beadloom ci` зелёный.
