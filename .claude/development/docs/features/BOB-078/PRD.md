# PRD — Качество группового диалога (пол · engagement · анти-повтор)

## Проблема (живые кейсы, команда зашла в группу: Владимир + Лиля + Паша)

Три нюанса, замеченные владельцем в реальном групповом диалоге:
1. **Пол/род не определяется.** Боб обратился к Лиле в МУЖСКОМ роде («он»), хотя её речь женского рода
   («Пошл**а** учить Python», «Пролистал**а** чат»).
2. **Игнор участника.** Лиля (гость) написала «Ты классный… Пошла учить Python» и реплику про Ant-Design —
   Боб ПРОМОЛЧАЛ (ambient, «ты»-обращение не распознано); Владимиру пришлось пнуть «Боб, чего молчишь».
3. **Повтор реплики.** Паше Боб дважды ДОСЛОВНО ответил «Паша, ну ты и циник. Интернет — свалка мусора…»
   (recall poisoning / few-shot мимикрия; анти-повтор не поймал точный дубль).

Все три бьют по north star «максимально человечен, не выглядит программно».

## Часть A — Пол/самоидентификация собеседника

🔴 **Принцип (Боб сам верно сформулировал в чате):** определять пол НЕ по имени (ненадёжно — «Саша»/
«Женя»), а по **самоидентификации** — как человек сам себя обозначает в речи.

**Сценарии:**
- Лиля пишет «Пошла…», «сама…» → Боб выводит fem → обращается к ней в женском роде.
- Собеседник «я сделал…», «я сам…» → masc.
- Недостаточно сигнала → **unknown → нейтрально** (без форсирования рода).
- Один родовой глагол в цитате/о 3-м лице НЕ должен перевесить — **накопление уверенности**.

**Инвариант A:** род выводится ТОЛЬКО из грамматики само-презентации собеседника; имя/паспорт — никогда.
Применяется к грамматике обращения Боба; unknown = нейтрально.

## Часть B — Engagement участников (не игнорить тёплое/«ты»)

🔴 **Корень:** batch-read (BOB-072) НЕ знает, что собеседник — гость/новичок (`BatchAmbientMessage` не
несёт `kind`), поэтому тёплая реплика/комплимент/знакомство читаются как низкая salience → IGNORE.

**Сценарии:**
- Новичок «Привет, я Лиля, пишу фронт» → Боб знакомится/отвечает (не молчит).
- Участник «Ты классный» (прямое «ты» к Бобу) → Боб реагирует (не игнор).
- НО: кросс-ток двоих между собой / «ты» к третьему → Боб НЕ влезает (баланс сохранён).

**Инвариант B:** соц-значимая реплика участника (комплимент/знакомство/прямое «ты» к Бобу) получает
ответ; «не баржить на всё» сохранено (точечно, не любой ambient).

## Часть C — Анти-повтор (без дословного само-дубля)

🔴 **Корень:** recall poisoning — Боб копирует свою яркую прошлую реплику дословно; анти-повтор
(BOB-026/032) не поймал точный дубль (вероятно stream-read reply-путь его обходит).

**Сценарии:**
- Боб не отправляет реплику, ДОСЛОВНО совпадающую с недавней своей (guard на точный/почти-точный дубль).
- Похожие подряд ответы («контекста мало», «GUPPI бы выдал справку») — разнообразятся (анти-few-shot нотка).

**Инвариант C:** дословный само-дубль недавнего ответа не отправляется (перегенерация/вариация).

## Не входит в scope
- Глубокая переработка read-the-room промпта (BOB-073) — здесь точечное правило engagement, не весь rewrite.
- Изменение authz/приватности.
