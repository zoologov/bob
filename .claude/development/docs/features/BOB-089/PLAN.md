## Критический путь

```
A (клон) ──► B (токены) ──► C (изоляция + смоук) ──► test ──► review ──► tech-writer
   └───────► D (идентичность + ссылка) ─────────────────┘
```

Самая рискованная точка — **C**: именно там выясняется, действительно ли отказ приходит по
правам. Если смоук покажет, что какой-то вектор жив, дизайн правится в C, а не после мёржа.

## Живой смоук — часть приёмки

🔴 Записано как критерий, а не «если останется время» (урок #38 — BOB-090 был объявлен
закрытым по зелёным гейтам, и первый же реальный разговор вскрыл дефект).

Эпик закрывается ПОСЛЕ того, как на настоящем git из клона Боба:
1. `git push` в апстрим → отказ **по правам**, с фактическим текстом отказа в отчёте;
2. `git update-ref refs/heads/main <sha>` → `main` owner'а не сдвинулся (доказать сравнением
   sha до/после в основном репозитории);
3. `git remote set-url` + push → отказ по правам;
4. легитимный путь — пуш ветки в форк — **работает**;
5. каждый из отказов проверен на кусачесть.

И честный итог: что стало невозможным **структурно**, а что осталось на доверии (модель
внутри клона по-прежнему делает с рабочим деревом что угодно — это не закрывается правами).
