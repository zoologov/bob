# RFC: BOB-033 — «Эмоциональная саморегуляция Боба»

> **Status:** Approved
> **Created:** 2026-06-25
> **Feature:** BOB-033 · реализует PRD BOB-033

---

## Контекст и опора (что уже есть)

- `Mood` (5 осей, `update`/`drift_toward`, домен, чистый) + `MoodDriftTick` (дрейф к `mood_baseline`).
- `UpdateMoodFromText` (perceive-шаг): Tier-0 sentiment→valence (±0.2), frequency→arousal, presence→
  social, late-night→arousal. **Это уже канал соц-зарядки — усилим его.**
- `ReflectTick` + `build_reflection_prompt` (BOB-026: грундинг недавними эпизодами + mood_tone) —
  генератор приватных мыслей; сейчас prior Qwen тянет в меланхолию.
- `InnerMonologueTick` (BOB-029 mood-conditioned, BOB-030 анти-крайности `_bounded_valence_delta`).
- Reply-recall — гибрид FTS+vector (`fts_recall.py`/vector), **без фильтра по `event_type`** → рефлексии
  всплывают в ответы. `leak_inner_life` (BOB-018, 12%) — явный показ ОДНОЙ свежей рефлексии.
- Канон-выравнивание состояния (mood-базлайн/phantoms/DB) — **сделано до этой фичи**.

## Решение по механизмам

### 1. Диспозиция — стабильный канон-позитивный аттрактор (новое)

`domain/personality/disposition.py`: чистый `Disposition(optimism: float, resilience: float)` (канон Боба
высокий, напр. `optimism≈0.8`). Это **черта, формирующая ДИНАМИКУ** (не само настроение): задаёт
(a) сдвиг валентности рефлексий, (b) вероятность реаппрайзала, (c) асимметрию соц-зарядки. `mood_baseline`
остаётся «точкой покоя»; диспозиция — «как сильно он тянется к хорошему». Персист: `data/soul/
disposition.json` (как `mood.json`), грузится в `SOUL` через `_load_soul`. Дефолт-канон при отсутствии.

### 2. Живые рефлексии (победить prior Qwen) — Tier-0

`build_reflection_prompt` расширяется: (a) **few-shot** 2-3 примера «живой бобовской мысли» (любопытные/
светлые/с юмором, иногда честно грустные — палитра, не монотон); (b) грундинг смещён к **недавним хорошим
эпизодам** (отбор по позитивной валентности из recent); (c) **valence-lean из диспозиции** в инструкции
(«мысль в духе твоего оптимизма, но честная»). Цель — сместить распределение мыслей к канону, не запрещая
минор. Tier-0 (приватность личностных внутренностей).

### 3. Реаппрайзал — «вытеснять плохое хорошим» (новое, вероятностно)

Новый шаг в `ReflectTick` (или отдельный `ReappraisalStep` за seam): после генерации мысли — классификация
её сентимента (Tier-0, как в `UpdateMoodFromText`). Если **негативная**, с вероятностью `p` (из
`disposition.optimism`, **seeded-RNG** для детерминизма) запускается **второй такт на Tier-1**: «найди в этой
мысли конструктив/хорошее, как сделал бы Боб» → переоценённая мысль **заменяет/дополняет** исходную и даёт
`MoodDelta` валентности вверх (через `_bounded_valence_delta`, BOB-030 — без крайностей). С вероятностью
`1-p` мысль остаётся честно грустной (человечно). **Приватность:** реаппрайзал-такт уходит на Tier-1
(облако) — осознанный компромисс owner ради качества; помечаем как точку пересмотра.

### 4. Социальная зарядка / co-regulation (симметричная, асимметрия в плюс)

Усиление `UpdateMoodFromText`: (a) **асимметричные шаги валентности** — позитив поднимает сильнее, чем
негатив опускает (напр. `+0.25` / `-0.12`, масштаб от `disposition`); (b) **вытеснение минора**: при
тёплом/энергичном входящем — дополнительная тяга настроения **к диспозиции/базлайну** (не просто +дельта,
а «зарядился — отпустило»); (c) грубость/холод — слабый спад (симметрия есть, но мягче). Всё в домене
`Mood` (новый метод напр. `lift_toward(disposition, rate)` или расширение дельты) — математика чистая,
use-case тонкий. Пропорционально силе сигнала, не механически.

### 5. Контейнмент мимикрии (рефлексии не образец для ответов)

Reply-recall **исключает `event_type='reflection'`** из пула образцов: либо параметр-фильтр в recall-порту,
либо пост-фильтр в `handle_message` перед compose. Влияние внутренней жизни идёт **через настроение→манеру**
(каналы 1-4), а не через копирование текста. `leak_inner_life` сохраняет **явный** доступ к свежей рефлексии
(осознанный показ ≠ слепое копирование). Сочетается с BOB-032 (анти-повтор реплик) — закрывает оставшийся
вектор (мимикрия рефлексий).

## Детерминизм и приватность

- Все вероятностные шаги (реаппрайзал, выбор few-shot) — через **инжектированный seeded-RNG** (как в
  проакте/целях), тесты детерминированы.
- Tier-0: генерация рефлексий + sentiment (личностное локально). **Tier-1 только реаппрайзал-такт**
  (компромисс owner) — единственный личностный поток в облако; задокументировать.

## Тестирование

- `Disposition` (домен, чистый); сдвиг валентности рефлексий; few-shot/grounding в промпте.
- Реаппрайзал: негативная мысль + RNG→reframe→mood↑ (детерминированно); RNG→остаётся грустной;
  только негатив триггерит; bounded (BOB-030) — без крайностей.
- Соц-зарядка: позитив поднимает сильнее негатива (асимметрия); тёплое вытесняет накопленный минор
  (тяга к диспозиции); грубость мягко опускает; пропорционально.
- Контейнмент: reply-recall не отдаёт reflection-эпизоды как образцы; `leak_inner_life` всё ещё может.
- Регрессии: mood/дрейф/BOB-030/BOB-032/recall-grounding фактов целы. ≥80%; `.venv/bin/*`; `beadloom ci`.

## Риски и границы

- **Механистичность/фальшь (главный риск, антипаттерн):** митигируем — всё **вероятностно/пропорционально**,
  минор разрешён, реаппрайзал не каждый раз. Ревью отдельно проверяет «не звучит ли как скрипт».
- **Runaway-позитив:** ограничен BOB-030 (анти-крайности) + ограниченной асимметрией + дрейфом.
- **Стоимость Tier-1:** реаппрайзал — редкий (только на негативной мысли × вероятность), не на каждом тике.
- **Приватность:** реаппрайзал на Tier-1 — задокументированный компромисс; при желании позже на локальную Ollama.

   соц-зарядки (`lift_toward`/асимметрия). Юнит-тесты.
2. **dev** — живые рефлексии (`build_reflection_prompt`: few-shot + good-grounding + valence-lean) +

3. **dev** — усиление `UpdateMoodFromText` (асимметрия + вытеснение минора) + контейнмент рефлексий из

5. **review** — человечно-не-механистично; приватность Tier-1-такта; без runaway/регрессий; DDD/детерминизм.
