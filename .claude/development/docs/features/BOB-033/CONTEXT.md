## Состояние

Боб эмоционально нестабилен, сползал в апатию/меланхолию при любом генезисе. Корень: Tier-0 Qwen
дефолтит рефлексии в меланхолию + нет человеческой саморегуляции + текст рефлексий копировался в
ответы. Канон-выравнивание текущего состояния (mood-базлайн `social 0.3→0.55` и т.д., phantoms,
DB) — **уже сделано**. BOB-030 (анти-крайности) и BOB-032 (анти-повтор реплик) — в main. Эта фича
строит **человеческую регуляцию**, из которой канон-оптимизм возникает сам.

## Ключевые решения (из PRD+RFC)

- **Моделируем, не скриптуем** — диспозиция (черта) + механизмы; позитив *возникает*, не приказан.
- **Человечность, не механистичность (антипаттерн!)** — реаппрайзал и зарядка **вероятностны/
  пропорциональны**; минор разрешён; иногда мысль остаётся честно грустной.
- **Внутренняя жизнь → настроение → манера** (оставляем); **дословное копирование текста** рефлексий
  в ответы — убираем (мимикрия ≠ манера).
- **Защита от депрессии — связь:** соц-зарядка (асимметрия в плюс) — главный анти-депрессант.
- 5 механизмов: диспозиция-аттрактор · живые рефлексии (few-shot+good-grounding, Tier-0) ·
  реаппрайзал (вероятностно, Tier-1-такт, mood↑ через BOB-030) · соц-зарядка (`UpdateMoodFromText`,
  `Mood.lift_toward`) · контейнмент рефлексий из reply-recall.
- **Детерминизм:** все вероятностные шаги через инжектированный seeded-RNG. **Приватность:** Tier-0
  генерация/сентимент; Tier-1 только реаппрайзал-такт (документированный компромисс).

## Стандарты кода (из CLAUDE.md §0.1)

- **Стек:** Python 3.12+ (asyncio), SQLite+FTS5+sqlite-vec, Ollama (Qwen Tier-0/1).
- **Архитектура:** DDD + Clean — `domain/` (чистое) ← `application/` ← `infrastructure/`; композиция в
  `app.py`; порты + Clock + **seeded-RNG** инжектируются (детерминизм).
- **Качество:** TDD; `.venv/bin/pytest -q -p no:cacheprovider` (uv run **висит**); `.venv/bin/ruff
  check src/ tests/`; `.venv/bin/mypy src/ tests/` (`--strict`); ≥80%.
- **Анти-паттерны:** без `Any`/`# type: ignore` без причины; без `print`/голого `except`/`import *`/
  мутабельных дефолтов; без `datetime.now()`/`random` напрямую (инжект Clock/RNG).
- **Документы:** русский. **Беады:** `--claim` перед, `bd close` после, чекпойнты `bd comments add`.
