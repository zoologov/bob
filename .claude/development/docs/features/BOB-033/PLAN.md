- [ ] За длинную сессию Боб держится канон-оптимистом, не сползает в апатию; спады реальны, но он выходит.
- [ ] Внутренняя жизнь живая/смешанная (не монотон-мрак); реаппрайзал и зарядка **вероятностны/

      настроение→манеру; **дословной мимикрии нет**.
- [ ] Без регрессий; cov ≥80%; `ruff`/`mypy --strict`/`beadloom ci` зелёные.
